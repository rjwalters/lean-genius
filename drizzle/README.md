# drizzle/

SQL migrations for the website's Cloudflare D1 database (`lean-genius-db`),
generated by `drizzle-kit` from `shared/db/schema.ts`.

- `0000_*.sql` … `0004_*.sql` — ordered migrations (five so far).
- `meta/_journal.json` and `meta/000N_snapshot.json` — drizzle-kit's migration
  journal and schema snapshots; do not edit by hand.

`drizzle.config.ts` (repo root) sets `schema: ./shared/db/schema.ts`,
`out: ./drizzle`, `dialect: sqlite`. To add a migration, change the schema and run
`npx drizzle-kit generate` (drizzle-kit is a devDependency; there is no package.json
script wrapping it).

`wrangler.toml` declares `migrations_dir = "drizzle"` on the `DB` binding, so
`wrangler d1 migrations apply lean-genius-db` (add `--local` for a local dev DB)
applies them. The runtime that reads these tables is under `functions/`.
