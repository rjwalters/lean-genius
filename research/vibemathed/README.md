# VibeMathed discovery-feed exploration (issue #43622)

This directory holds a one-off snapshot + join analysis of
[VibeMathed](https://vibemathed.com/), a community-curated database of math
problems "first solved with AI in the loop", evaluated as a potential
discovery feed / status-drift check for this repo's Erdős-problem gallery.

## Contents

- `dataset-snapshot.json` — raw snapshot of `GET https://vibemathed.com/api/dataset`,
  fetched 2026-08-03/04. 427 problems, 41 fields each.
- `join.py` — joins the dataset's Erdős-tagged entries against
  `src/data/proofs/erdos-*/meta.json` on Erdős problem number and writes
  `join-results.json`. Read-only: it does not modify any gallery `meta.json`
  file. Run with `python3 research/vibemathed/join.py` from the repo root.
- `join-results.json` — machine-readable join output (generated by `join.py`;
  regenerate by re-running the script against a fresh dataset snapshot).
- `report.md` — human-readable findings: overlap size, mapping rate,
  triage-candidate lists, and recommendations.
