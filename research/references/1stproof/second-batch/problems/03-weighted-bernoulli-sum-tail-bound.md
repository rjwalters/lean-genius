# Problem 3: Values of p with Pr[sum w_i v_i >= p] >= p for weighted Bernoulli sums

- **Area:** probability theory
- **Source:** [problems.json](https://github.com/1stproof/batch-2/blob/main/batch-2-raw-outputs/Batch2Problems/problems.json) (upstream id `prob-003`)
- **Slug:** `weighted-bernoulli-sum-tail-bound`

## Statement (verbatim LaTeX from upstream)

```latex
{\bf Problem:} Let $w_1, \ldots, w_m$ be non-negative real numbers such that $\sum_{i=1}^m w_i=1$, and let 
$v_1, \ldots, v_m$ be i.i.d. Bernoulli$(p)$ random variables. For which values of probability $p$ is it true that
\[\Pr\Big[\sum_{i=1}^m w_i v_i\geq p\Big]\geq p?\]
```
