## S4 ACT plan (Sub-Milestone B+)

Detailed in `state.md` `## Next Action`. Summary:

```lean
-- Target file: proofs/Proofs/LegendrePrimeGapEquivalence.lean
theorem legendre_iff_primeGap :
    LegendreConjecture ↔
      ∀ k, Nat.nth Nat.Prime (k + 1) - Nat.nth Nat.Prime k
        ≤ 2 * Nat.sqrt (Nat.nth Nat.Prime k) + 1
```

**Key Mathlib lemmas** (verify signatures at lake-pin time):
- `Nat.sqrt_eq` / `Nat.sqrt_lt_iff` / `Nat.lt_succ_sqrt'`.
- `Nat.nth_prime` API (`Nat.Data.Nat.Prime.Nth`, already imported).
- `Nat.nth_prime_succ_le_of_prime_gt` from
  `proofs/Proofs/PrimeGapBounds.lean:123` (in-repo, not Mathlib).

**Outline**:
- Forward (`legendre → gap bound`): apply Legendre at
  `n := Nat.sqrt (Nat.nth Nat.Prime k)`; get prime `q` in
  `(n², (n+1)²)`; minimality of `Nat.nth Nat.Prime (k+1)` gives
  `Nat.nth Nat.Prime (k+1) ≤ q < (n+1)² = n² + 2n + 1`.
- Reverse (`gap bound → legendre`): for `n ≥ 1`, find largest `k` with
  `Nat.nth Nat.Prime k ≤ n²`; apply gap bound to get
  `Nat.nth Nat.Prime (k+1) ≤ n² + 2n + 1 = (n+1)²`; this is the
  Legendre witness via `legendreAt_iff_halfOpen` (from iter-2).

**Estimated size**: +100 to +180 LOC. 0 new axioms expected.

**Build risk**: LOW. Pure number-theoretic reasoning over `Nat`. No
new Mathlib imports beyond what `LegendreGapEquivalence.lean` already
brings. Should build with `lake build` in a healthy environment.
