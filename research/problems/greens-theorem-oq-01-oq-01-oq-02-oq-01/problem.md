# Problem: n-Dimensional intervalIntegral_swap via Measure.pi

## Statement

### Plain Language

The parent gallery proof `greens-theorem-oq-01-oq-01-oq-02`
(`Proofs/GreensTheoremOQ01OQ01OQ02.lean`, 231 lines, 0 sorries) provides
a standalone `intervalIntegral_swap`:

```
∫ y in c..d, ∫ x in a..b, f x y = ∫ x in a..b, ∫ y in c..d, f x y
```

for `f : ℝ → ℝ → ℝ`, with three increasingly-general variants (ordered,
general-`uIcc`, continuous). The 2D theorem reduces, in each of four
ordering cases, to Mathlib's underlying Lebesgue Fubini
`MeasureTheory.integral_integral_swap`.

Open Question OQ-04 from that entry asks:

> Can `intervalIntegral_swap` be generalized to **n-dimensional** iterated
> integrals via `Measure.pi`, providing
> ```
> ∫ x_0 in a_0..b_0, ∫ x_1 in a_1..b_1, … ∫ x_{n-1} in a_{n-1}..b_{n-1}, f x
>   = ∫ x_{σ(0)} in a_{σ(0)}..b_{σ(0)}, … f x
> ```
> for any permutation `σ : Equiv.Perm (Fin n)`?

### Formal Statement (S2+ goal shape)

```lean
-- n-fold iterated interval integral
noncomputable def iteratedIntervalIntegral
    {n : ℕ} (a b : Fin n → ℝ) (f : (Fin n → ℝ) → ℝ) : ℝ := by
  -- defined by Fin.induction so the body is
  -- ∫ x_0 in a 0 .. b 0, … ∫ x_{n-1} in a (n-1) .. b (n-1), f (fun i => x_i)
  sorry

-- main result: permutation invariance
theorem iteratedIntervalIntegral_perm {n : ℕ}
    (a b : Fin n → ℝ) (f : (Fin n → ℝ) → ℝ)
    (σ : Equiv.Perm (Fin n))
    (hf_meas : Measurable f)
    (hf_int  : Integrable f
      (MeasureTheory.Measure.pi
        (fun i => MeasureTheory.volume.restrict
                    (Set.uIcc (a i) (b i))))) :
    iteratedIntervalIntegral a b f
      = iteratedIntervalIntegral (a ∘ σ) (b ∘ σ) (f ∘ (Equiv.piCongrLeft' _ σ.symm)) := by
  sorry
```

The deliverable is a **finite-`n` proof template** modelled on the 2D
proof in the parent file, plus the algebraic argument that adjacent
transpositions generate `Equiv.Perm (Fin n)` and that each adjacent swap
reduces to the parent's `intervalIntegral_swap`.

## Theoretical Setup

### The 2D anchor

`GreensTheoremOQ01OQ01OQ02.intervalIntegral_swap` (parent file, lines
82–174) handles all four `(a≤b ∨ b<a) × (c≤d ∨ d<c)` orderings by
sign-flip identity `∫ x in a..b f = -∫ x in b..a f`. The ordered case
is closed by:

```
hf_ioc.mono_measure (Measure.prod_mono …) -- Icc → Ioc restriction
exact (MeasureTheory.integral_integral_swap hf_ioc).symm
```

so the underlying Mathlib Lebesgue Fubini is `integral_integral_swap`
on `(volume.restrict (Ioc a b)).prod (volume.restrict (Ioc c d))`.

### Three independent obstacles for n ≥ 3

1. **Defining the n-fold iterated interval integral.**
   The 2D form `∫ y in c..d, ∫ x in a..b, f x y` is a 1D `intervalIntegral`
   of a function `ℝ → ℝ` that itself returns a 1D `intervalIntegral`.
   For general `n`, the most natural definition is recursive in `n` via
   `Fin.induction`, with the inner function being the iterated integral
   over `Fin (n-1) → ℝ`. Care is required to convert between
   `Fin (n+1) → ℝ` and `ℝ × (Fin n → ℝ)` via
   `Equiv.piFinSuccAboveEquiv` (or `Fin.consEquiv`).

2. **Permutation-invariance proof strategy.**
   `Equiv.Perm (Fin n)` is generated by adjacent transpositions
   `Equiv.swap i (i+1)`. The proof reduces to:
   - **Adjacent swap lemma**: if positions `i, i+1` are swapped, the
     iterated integral is unchanged. This is the 2D
     `intervalIntegral_swap` applied to the iterated form
     `∫ x_i .. ∫ x_{i+1} .. (rest)`.
   - **Generation lemma**: every `σ` factors as a product of adjacent
     transpositions, and the iterated integral is invariant under
     composition.

3. **Measurability and integrability propagation.**
   The hypothesis is integrability on the product
   `Measure.pi (fun i => volume.restrict (uIcc (a i) (b i)))`.
   Permutation invariance of `Measure.pi` under reindexing is
   `MeasureTheory.measurePreserving_piCongrLeft` (or a `Measure.pi`-specific
   variant). Integrability of `f ∘ Equiv.piCongrLeft' _ σ.symm` w.r.t.
   the permuted `Measure.pi` is then automatic via
   `Integrable.comp_measurePreserving`.

## Theoretical Obstacle: Why `Measure.pi` is harder than `Measure.prod` for `uIcc`

The parent's 2D proof uses
`(volume.restrict (uIcc a b)).prod (volume.restrict (uIcc c d))`
and the Mathlib identity
`(volume.restrict S).prod (volume.restrict T) = volume.restrict (S ×ˢ T)`
(via `restrict_prod_eq_prod_restrict`). The n-dim analogue
`Measure.pi (fun i => volume.restrict (uIcc (a i) (b i)))
   = volume.restrict (Set.pi univ (fun i => uIcc (a i) (b i)))`
is provable but requires `Measure.pi_restrict` (or a hand proof from
`Measure.pi_pi` on the box generators). At S1 this is a Mathlib-gap
candidate — `Mathlib.MeasureTheory.Constructions.Pi` provides
`pi_pi` for the unrestricted product but the `restrict` analogue
must be either located or re-proved.

A second, more subtle obstacle: **the sign-flip identity
`∫ x in a..b f = -∫ x in b..a f` is per-axis**, so the parent's 4-case
analysis becomes a `2^n`-case analysis for n axes. The clean route
is to do the entire proof under the symmetric `uIcc`-restricted
`Measure.pi`, deducing the four 2D orderings from the
`uIcc`-symmetric statement only at extraction time. Equivalently,
the S2+ deliverable should target a statement of the form

```
∫ x_0 in uIoc (a 0) (b 0), … ∫ x_{n-1} in uIoc (a (n-1)) (b (n-1)), f x
  · ∏ i, sign (b i - a i)
  = (the σ-permuted analogue with the same sign product)
```

so the case-split is **absent** from the proof — only the per-axis
sign factor appears.

## Theoretical Obstacle: Bochner vs scalar target

Mathlib's `integral_integral_swap` generalises to Bochner-valued
integrals (`f : α × β → E` for a Banach space `E`). The n-dim
analogue should likewise be Bochner-polymorphic. The parent file
is scalar (`f : ℝ → ℝ → ℝ`), so OQ-02 (Bochner generalisation of the
parent) is a sibling open question. S1 of OQ-04 focuses on
`f : (Fin n → ℝ) → ℝ` to keep the surface small; an S5+ extension
to `f : (Fin n → ℝ) → E` is natural.

## Why It Matters

- **Mathlib contribution surface.** A clean
  `MeasureTheory.iteratedIntervalIntegral_perm` would close a
  Mathlib gap that affects every multi-variable calculus
  formalisation: changing-of-variables under coordinate permutation,
  iterated integral commutativity, Fubini for higher-dim Stokes-style
  theorems.
- **Bridge to Stokes / divergence theorem.** The gallery has
  `FundamentalTheoremCalculusStokes` and several Green's-theorem
  descendants; an n-dim Fubini is the natural successor.
- **Algorithmic-by-induction template.** The proof technique
  (factor `σ` into adjacent transpositions, induct on the factor
  length) is reusable for many "permutation-invariance" lemmas in
  measure theory.

## Suggested Decomposition

- **S2**: define `iteratedIntervalIntegral` via `Fin.induction` (or
  equivalent) and prove the **`n=2` reduction lemma**: the new
  definition specialises to the parent's
  `∫ y in c..d, ∫ x in a..b, f x y` when `n = 2`. (Cosmetic, but
  necessary to inherit the parent.) ~40 lines.
- **S3**: prove the **adjacent-swap lemma**: for `i : Fin n` with
  `i.castSucc < Fin.last n`,
  `iteratedIntervalIntegral a b f = iteratedIntervalIntegral
     (a ∘ Equiv.swap i.castSucc i.succ) (b ∘ …) (f ∘ …)`.
  Reduces to the parent's 2D `intervalIntegral_swap` by peeling
  off the first `i` integrals. ~80 lines.
- **S4**: prove the **permutation-invariance** main result by
  factoring `σ` into adjacent transpositions (via
  `Equiv.Perm.swap_induction_on'` or a manual `List.swap`-decomposition)
  and chaining S3. ~50 lines + lemma-finding overhead.
- **S5 (optional, deferred)**: Bochner generalisation
  (`f : (Fin n → ℝ) → E`) and `Measure.pi_restrict` Mathlib gap.
