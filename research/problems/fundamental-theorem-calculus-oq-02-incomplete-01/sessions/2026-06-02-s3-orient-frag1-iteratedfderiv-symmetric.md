## Target

```lean
-- Proposed Fragment 1 theorem (n-dim Schwarz):
theorem iteratedFDeriv_symmetric_of_contDiff
    {E F : Type*} [NormedAddCommGroup E] [NormedSpace ℝ E]
    [NormedAddCommGroup F] [NormedSpace ℝ F]
    {f : E → F} (hf : ContDiff ℝ ⊤ f) (n : ℕ) (x : E) (σ : Equiv.Perm (Fin n))
    (m : Fin n → E) :
    iteratedFDeriv ℝ n f x m = iteratedFDeriv ℝ n f x (m ∘ σ)
```

The conclusion says the continuous multilinear map `iteratedFDeriv ℝ n f x` is invariant
under permuting its `Fin n` arguments — i.e., is symmetric as an n-multilinear form. This
specialises to `second_derivative_symmetric` at `n = 2` and `σ = swap 0 1`.

## Induction skeleton (sketch)

The induction is on `n`. Base case n = 0, 1: trivially symmetric (no permutation acts).
Base case n = 2: direct application of B1.

Inductive step: assume `iteratedFDeriv ℝ n f x` is symmetric under all of `Equiv.Perm (Fin n)`.
For `iteratedFDeriv ℝ (n+1) f x` and an arbitrary `σ ∈ Equiv.Perm (Fin (n+1))`:

**Step 1** — reduce to adjacent transpositions. By B8 + B10, `σ` is a product of adjacent
transpositions `τᵢ = swap i (i+1)`. By group homomorphism property of the symmetric-action
map, it suffices to show `iteratedFDeriv ℝ (n+1) f x (m ∘ τᵢ) = iteratedFDeriv ℝ (n+1) f x m`
for each adjacent τᵢ.

**Step 2** — split adjacent τᵢ into two cases:
  - `i = 0`: swap of arguments 0 and 1. Goal: `f^(n+1) (m 0, m 1, m 2, …) = f^(n+1) (m 1, m 0, m 2, …)`.
    Use B4 to peel one `fderiv`: `f^(n+1) = fderiv (f^n)`. The 2D Schwarz B1 applied to
    `f^(n-1)` (as a function of *two* derivative arguments) gives the swap-01 symmetry.
  - `i ≥ 1`: swap of arguments i and i+1 *inside* the tail. Goal: by B4,
    `f^(n+1) x m = fderiv (f^n) x (m 0) (Fin.tail m)`. The swap τᵢ doesn't touch `m 0`,
    so it's the swap (i-1, i) inside `Fin.tail m`, which is an adjacent transposition in
    `Equiv.Perm (Fin n)`. By IH, `f^n` is symmetric under `Equiv.Perm (Fin n)`, so
    `f^n` evaluated at `(Fin.tail m) ∘ swap (i-1) i = (Fin.tail m)`. QED for this case.

The hard part is Step 2 case `i = 0`. It requires showing that applying `fderiv` once
"exposes" two derivative arguments that can be swapped via 2D Schwarz, working *inside*
the higher-order currying. This is the subtle step: it likely requires the dual B6/B7
machinery to push `m 0` into "innermost" position, then apply Schwarz, then re-shuffle.
