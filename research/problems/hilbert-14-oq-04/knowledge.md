# hilbert-14-oq-04 — Knowledge base

## Algorithmic landscape

### Reductive groups: SOLVED algorithmically (Derksen 1999)

For `G` reductive (over `char 0`) acting linearly on `V = k^n`, Derksen
gave an algorithm to compute generators of `k[V]^G`:

1. **Reynolds operator** `R : k[V] → k[V]^G`, the projection averaging
   over the (Haar measure of the) group.
2. **Hilbert nullcone** `N_G(V) = V(I_G)` where
   `I_G = (f_1, …, f_m)` is the ideal of homogeneous invariants of
   positive degree.
3. **Algorithm**: compute generators of the nullcone ideal `I_G` via
   linearization (`σ : G × V → V × V`, `(g, v) ↦ (v, g · v)`), and recover
   `k[V]^G = R(k[V]) = R(I_G^{closure})`.
4. **Termination**: degree bound comes from the **null cone** dimension
   plus Hilbert's basis theorem applied to the ideal generated by lifts
   of nullcone equations.

For **finite** groups (a special case of reductive), Noether's bound
`deg(generators) ≤ |G|` gives a tighter, more elementary algorithm:
enumerate symmetric products of orbits up to degree `|G|`.

### Unipotent / non-reductive: ALGORITHMIC GAP

For a single locally nilpotent derivation (LND) `D : k[V] → k[V]`
(= a `G_a` action), the situation splits into three regimes:

**Decidable subcases**:
- `n ≤ 4` variables, `D` LND: `ker D` is always f.g.; van-den-Essen-Tan
  algorithm via the "Dixmier-Maeda" Gröbner-basis trick computes
  generators.
- "Triangular" or "elementary" LNDs (`D x_i ∈ k[x_1, …, x_{i-1}]`):
  `ker D` always f.g.; explicit recursive algorithm.

**Open regime**:
- `n = 5`: open in general. Some progress (Daigle-Freudenburg).
- `n ≥ 7` (Roberts) and `n ≥ 13` (Nagata): non-f.g. examples known, but
  **no algorithm** distinguishes them from f.g. cases uniformly.

For **direct products** `G_a^k` and **semidirect products with finite
groups**, partial results (Tanimoto, Hashimoto-Miyazaki) cover special
representation types but no uniform algorithm.

### Larger unipotent groups (`U_n` upper-triangular)

For `U_n` (upper unitriangular in `GL_n`), Pommerening-Hadziev (1966)
proved finite generation under quotient extensions, but the algorithmic
question remains open in many cases.

## Key technique: Reynolds operator for finite groups

For `G` finite with `|G|` invertible in `k`:

```
  R : k[V] → k[V]^G
  R(f) = (1/|G|) ∑_{g ∈ G} g · f
```

**Properties**:
1. `R` is `k`-linear.
2. `R(f) = f` for `f ∈ k[V]^G`.
3. `R(f · h) = f · R(h)` for `f ∈ k[V]^G` (the "Reynolds identity").
4. `R(f)` has the same degree as `f` (the action preserves degree).

**Noether's proof of finite generation** (1916):
- The image `R(I)` of any homogeneous ideal `I ⊆ k[V]` is generated (as a
  `k[V]^G`-module) by `R(f_1), …, R(f_m)` whenever `I = (f_1, …, f_m)`.
- Apply to `I = (V^+)` the irrelevant ideal of positive-degree polynomials:
  `R(I) = (k[V]^G)^+`, the irrelevant ideal of invariants.
- Since `k[V]` is Noetherian, `(V^+)` is finitely generated; hence so is
  `R(V^+) = (k[V]^G)^+`. By the **graded Nakayama**, generators of the
  irrelevant ideal generate `k[V]^G` as a `k`-algebra.

**Noether bound**: For `char k = 0` or `char k ∤ |G|`, the generators have
degree `≤ |G|`. Hence the algorithm: enumerate all monomials of degree
`≤ |G|`, average each via `R`, and Gauss-eliminate to produce a basis.

## Key technique: Locally nilpotent derivations

A `k`-derivation `D : R → R` is **locally nilpotent** if for every `f ∈ R`
there exists `N` with `D^N f = 0`.

**Correspondence (char 0)**: LNDs on `R` are in bijection with
algebraic `G_a`-actions on `Spec R`:

```
  D ⟷ φ : G_a × Spec R → Spec R,   φ_t = exp(t · D).
```

**Fundamental facts**:
- `ker D ⊆ R` is a subalgebra (since `D` is a derivation and locally
  nilpotent).
- `R^{G_a} = ker D` (Lie-algebraic version of "invariants of a
  one-parameter group").
- **Slice theorem**: If `D s = 1` for some `s ∈ R`, then `R = (ker D)[s]`,
  i.e. `R` is a polynomial ring in one variable over `ker D`. In
  particular, `ker D` is f.g. iff `R` is (which is the case for `R = k[V]`).
- Without a slice, `ker D` can still fail to be f.g. (Roberts 1990).

**Van den Essen's algorithm (2000)**:
- Given `D` triangular or admitting a "local slice" `s` with `Ds` a
  unit times a power, compute `ker D` as `R[s^{-1}] ∩ R`, the
  intersection of a localized polynomial ring with `R`. This intersection
  is computable via Gröbner bases.

## Counterexamples

### Nagata (1959): G_a^13 ⟶ k^32

Let `V = k^32` with basis `{x_i, y_i, z_j : 1 ≤ i ≤ 16, 1 ≤ j ≤ 16}`.
`G_a^13` acts via
```
  (t_1, …, t_13) · z_j  =  z_j  +  ∑_i a_{j,i} t_i x_i  +  ∑_i b_{j,i} t_i y_i
```
where `(a_{j,i}), (b_{j,i})` form a "generic" matrix (16 rows, 13
columns, rank 13). Invariant ring:
```
  k[V]^{G_a^13}  =  k[x_1, …, x_16, y_1, …, y_16, F_1, F_2, F_3, …]
```
with infinitely many "new" polynomial invariants `F_j` of growing
degrees. **Not finitely generated.**

### Roberts (1990): G_a^6 ⟶ k^7

A simpler counterexample with 7 indeterminates and 6 commuting LNDs.
The construction exploits a Veronese embedding of a non-finitely-generated
section ring of a smooth surface.

### Why these matter for OQ-04

These show that **finite generation is not a property of the input
(group, representation) decidable by structural inspection**. Any
algorithmic resolution must do more than check the group's Levi
decomposition — it must analyze the *specific* representation. Whether
such analysis is uniformly computable is the OQ-04 conjecture.

## Mathlib-tractable adjacent theorems

### (A) Hilbert-Noether finiteness theorem (S2 target)

**Statement (informal)**: Let `G` be a finite group acting linearly on
`V = k^n` over a field `k` with `char k ∤ |G|`. Then `k[V]^G` is finitely
generated as a `k`-algebra.

**Lean encoding (proposed)**:
```lean
variable {k : Type*} [Field k] {n : ℕ} {G : Type*} [Group G] [Fintype G]
  [Module k V]   -- where V := Fin n → k or similar
variable [MulAction G V]    -- linear G-action
variable [Invertible (Fintype.card G : k)]   -- |G| invertible

theorem hilbert_noether_finite :
    (k[V]^G : Subalgebra k (k[V])).FG  := …
```

**Proof outline (10 lines + supporting lemmas)**:
1. Define Reynolds operator `R : k[V] → k[V]` as `R f = (1/|G|) ∑_g g•f`.
2. Show `R` is `k[V]^G`-linear and idempotent.
3. By Hilbert basis, the maximal ideal `m = (x_1, …, x_n)` of `k[V]` is
   f.g. as an ideal.
4. Apply `R` to obtain that `R(m) = m ∩ k[V]^G` is a f.g. ideal of
   `k[V]^G`.
5. Graded Nakayama: generators of `m ∩ k[V]^G` generate `k[V]^G` as a
   `k`-algebra.

**Mathlib references**:
- `Mathlib.Algebra.MvPolynomial.Basic` — polynomial ring over `k`.
- `Mathlib.Algebra.Module.LinearMap` — `LinearMap` for `R`.
- `Mathlib.Algebra.Algebra.Subalgebra.Basic` — `Subalgebra` and
  `Algebra.adjoin`.
- `Mathlib.RingTheory.Noetherian.Basic` — `IsNoetherian`, `Submodule.FG`.
- `Mathlib.GroupTheory.GroupAction.Defs` — `MulAction`, fixedPoints.

**Gap**: no Reynolds operator in Mathlib. Define from scratch.
