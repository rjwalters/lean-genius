## Structural diagnosis

**Walk-vanishing on (5,3,2).**  Of the two structural c'-column
crossings `(0,1)` and `(1,1)`, only `(1,1)` is walk-vanishing:
* In `μ = (5,3,2)`: `H*((1,1)) = {(1,2), (2,1)}`, both corners
  ≠ c, so `gnwProb μ c K (1,1) = 0` at K=1 and stably.
* In `μ\c' = (5,3,1)`: `H*((1,1)) = {(1,2)}`, corner ≠ c.

`(0,1)` is **not** walk-vanishing on either side: the strict

## The structural algebraic identity (★)

**Claim.**  For any `x = (i, c'.2)` with `i < c'.1` (a c'-column
crossing candidate),

```
gnwProb μ c K x · (h_d − 1)² − gnwProb (μ\c') c K x · h_d · (h_d − 2)
  =  gnwProb μ c K x  −  h_d · (h_d − 2) · (gnwProb (μ\c') c K x − gnwProb μ c K x).
```

**Proof.**  `(h_d − 1)² − h_d · (h_d − 2) = (h_d² − 2 h_d + 1) − (h_d² − 2 h_d) = 1`.
Hence

```
pμ · (h_d − 1)² − pν · h_d(h_d − 2)
  = pμ · (h_d(h_d − 2) + 1) − pν · h_d(h_d − 2)
  = pμ + h_d(h_d − 2) · (pμ − pν)
  = pμ − h_d(h_d − 2) · Δp,                     where Δp := pν − pμ.
```

∎

**Consequence (combine with S57.5's case-1 leg reduction).**
S57.5's `sum_gnwProb_leg_of_c'_reduce_case1` (PR #17865, merged)
states, for the c'-column sum over `r ∈ range c'.1`:

```
∑ r ∈ range c'.1, gnwProb μ c K (r, c'.2)
  = ∑ r ∈ range (c.1 + 1), gnwProb μ c K (r, c'.2)
```

**For `c.1 = 0`** (true for all seven test diagrams in this
program), this reduces to the single term `pμ(0)`.  Applying the
same lemma to `μ\c'` (PR #17865 / S57.5 also discharges this — the
"high-row block vanishes" via `gnwProb_unreachable_zero`'s `Or.inl`
disjunct, which depends only on the `(r > c.1) ∨ (x.2 < c.2)`
condition, both invariant under c'-removal at off-spine cells):

```
∑ r ∈ range c'.1, gnwProb (μ\c') c K (r, c'.2)
  = ∑ r ∈ range (c.1 + 1), gnwProb (μ\c') c K (r, c'.2)
  = pν(0).
```

Hence the **c'-column total residual** for `c.1 = 0`:

```
(★)   c'-col residual  =  pμ(0)  −  h_d · (h_d − 2) · (pν(0) − pμ(0)).
```

## Why (★) holds without further data

(★) is purely algebraic: it is the trivial identity
`(h_d − 1)² − h_d(h_d − 2) = 1` applied to S57.5's already-proved
range-reduction.  No combinatorial conjecture; no further data
needed.  The "more data points needed" line in S69 referred to
the question of whether `−|c-arm region|` extended beyond
single-non-vanishing-crossing shapes — that question is now
*moot*: (★) is the correct formula, expressed in terms of
`gnwProb` directly rather than a count of c-arm cells.

## Walk-vanishing and (★)

If `(0, c'.2)` is walk-vanishing (extremely rare for `i = 0` in
case-1 shapes because `(0, c'.2)`'s strict hook contains
`(0, c.2) = c` in row 0 whenever `c.2 > c'.2`, which is the
case-1 condition), then `pμ(0) = pν(0) = 0` and (★) yields
`c'-col residual = 0`.

For `i = 0 < c'.1`, walk-vanishing requires the strict hook
`H*((0, c'.2))` in `μ` to contain no path to `c = (c.1, c.2)`.
The arm at `(0, c'.2)` includes `(0, c'.2+1), …, (0, c.2 − 1),
(0, c.2)`; the last is `c` itself.  So `(0, c'.2)` can only be
walk-vanishing if `c.2 ≤ c'.2`, contradicting case-1's
`c'.2 < c.2`.  **For `c.1 = 0`, `(0, c'.2)` is never walk-vanishing.**

Walk-vanishing therefore only kicks in for `(i, c'.2)` with
`i ≥ 1`, which are eliminated from the sum by S57.5's reduction
for `c.1 = 0`.  Hence the walk-vanishing classification
introduced in S69 is **already invisible** under (★) for the
case `c.1 = 0`: the walk-vanishing crossings sit in the
`(c.1, c'.1)`-range that S57.5 collapses to zero.

## Implication for `F_side_identity_aligned`'s proof

For `c.1 = 0` (case 1) — covering all S62–S70 tests — S57.7's
**c'-column sub-lemma** can now be stated as a precise, proved-
modulo-`pμ`/`pν`-values identity:

```
S57.7 c'-column sub-lemma (case-1, c.1 = 0):
  ∑ r ∈ range c'.1, [gnwProb μ c (h_μ (r,c'.2)) (r,c'.2) · (h_d−1)²
                      − gnwProb (μ\c') c (h_(μ\c') (r,c'.2)) (r,c'.2) · h_d(h_d−2)]
    =  gnwProb μ c (h_μ (0,c'.2)) (0,c'.2)
       − h_d(h_d − 2) · (gnwProb (μ\c') c (h_(μ\c') (0,c'.2)) (0,c'.2)
                          − gnwProb μ c (h_μ (0,c'.2)) (0,c'.2)).
```

The K-bookkeeping (different stable K thresholds for μ vs.
μ\c') is handled by **S57.6 prep 2's
`gnwProb_eq_on_leg_class_case1`** and the K-monotonicity past
the stable threshold (`gnwProb_succ_K_eq_K` style lemmas in
Helpers.lean, ~line 14600).

What remains for S57.7's c'-column to land **as a Lean lemma**:

1. **Discharge the algebraic step** (★) — definitionally trivial
   `(h_d − 1)² = h_d(h_d − 2) + 1`, then `ring` or `nlinarith`.
2. **Invoke S57.5's reduction** twice (once for `μ`, once for
   `μ\c'`); the `μ\c'` invocation needs a corollary
   `sum_gnwProb_leg_of_c'_reduce_case1_removed` — same statement
   on `removeCorner μ c' hc'`, provable by transferring
   `gnwProb_unreachable_zero`'s `Or.inl` disjunct (`r > c.1`,
   invariant under c'-removal).
3. **For `c.1 = 0`**, the resulting single term is the closed-form
   `pμ(0) − h_d(h_d − 2) · (pν(0) − pμ(0))`.

The off-spine sub-lemma is the remaining open piece for S57.7
proper — `F_side_identity_aligned`'s off-spine residual on
`(5,3,2)` is `+8/3` (cells `(0,2), (0,3), (0,4)`), and the

NEGATION of the c'-column residual (the c'-row residual is 0 by

so an algebraic identity dual to (★) — applied to off-spine
cells `(0,j)` with `c'.2 < j ≤ c.2` — should yield the same
closed-form.  **Recommended S71** to nail that algebraic
