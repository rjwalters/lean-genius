#### `gnwProb_zero_of_row_eq_c'_case1` (line 14722, ~10 lines)

```lean
private lemma gnwProb_zero_of_row_eq_c'_case1
    {μ : YoungDiagram} {c c' : ℕ × ℕ}
    (hc1 : c.1 < c'.1) (x : ℕ × ℕ) (hx : x.1 = c'.1) (K : ℕ) :
    gnwProb μ c K x = 0 := by
  apply gnwProb_unreachable_zero K x
  exact Or.inl (by omega)
```

**Statement**: per-cell vanishing of `gnwProb μ c K x` when the
target corner `c` lies strictly above the cell `x`'s row, with the
row identified via the equality `hx : x.1 = c'.1` rather than a
literal pair construction `(c'.1, _)`.

**Why a separate lemma from PR #17605's
`sum_gnwProb_arm_of_c'_eq_zero_case1`.**  The summand-form lemma
indexes over a literal `Finset.range c'.2` of natural numbers,
constructing cells via `(c'.1, s)`.  When the joint K-induction's
S57.7 assembly partitions `(removeCorner μ c' hc').cells` into
cell-type subsets via
`Finset.filter (fun x => x.1 = c'.1 ∧ x ≠ c')`, the natural
reduction applies `Finset.sum_eq_zero` over the *filtered* `Finset`
whose elements are `x : ℕ × ℕ` carrying the predicate as a
hypothesis — not the literal pair construction.  This per-cell
form lets `Finset.sum_eq_zero` discharge the goal directly without
inserting an extra `Finset.sum_image` step (the pair-construction
injection `s ↦ (c'.1, s)`).

**Proof.** Apply `gnwProb_unreachable_zero K x` and discharge the
disjunction with `Or.inl`.  The implicit `c.1 < x.1` substitution
follows from `hx : x.1 = c'.1` and `hc1 : c.1 < c'.1` via `omega`
on ℕ.

#### `gnwProb_zero_of_col_eq_c'_case2` (line 14742, ~10 lines)

```lean
private lemma gnwProb_zero_of_col_eq_c'_case2
    {μ : YoungDiagram} {c c' : ℕ × ℕ}
    (hc2 : c.2 < c'.2) (x : ℕ × ℕ) (hx : x.2 = c'.2) (K : ℕ) :
    gnwProb μ c K x = 0 := by
  apply gnwProb_unreachable_zero K x
  exact Or.inr (by omega)
```

Mirror of the arm-of-c' variant for the column-disjunct of
`gnwProb_unreachable_zero`.

### Genericity and downstream consumption

Both lemmas are universal in their `μ` argument (since
`gnwProb_unreachable_zero` is), so they apply equally to:
* The LHS sum of `F_side_identity_aligned`: `gnwProb μ c (h_μ x) x`,
  specializing `K := hookLength μ x.1 x.2`.
* The RHS sum: `gnwProb (removeCorner μ c' hc') c (h_{μ\c'} x) x`,
  specializing `K := hookLength (removeCorner μ c' hc') x.1 x.2`.

Together with PR #17605's two summand-form lemmas, the four
S57.3+S57.3a lemmas package S57.2's `gnwProb_unreachable_zero` for
both the literal-pair-summand form (PR #17605) and the
filtered-cell form (this PR) needed at downstream call sites of
the joint K-induction.
