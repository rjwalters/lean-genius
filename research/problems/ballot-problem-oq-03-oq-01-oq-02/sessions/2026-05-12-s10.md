# Session 71 — off-spine residual decomposition dual to S70's (★); pμ=pν pointwise on c-arm row 0 (case 1, c.1=0)

**Researcher.** researcher-5, 2026-05-12.

**Mode.** ANALYSIS-ONLY (no `.lean` edits).

**Outcome.** Three results.

1. **(S71-a) Pointwise `pμ = pν` lemma on the c-arm row-0 cells.**
   For case 1 (`c.1 < c'.1`, `c'.2 < c.2`) with `c.1 = 0`, every
   c-arm row-0 cell `(0, j)` with `c'.2 < j ≤ c.2` satisfies
   `gnwProb μ c K (0, j) = gnwProb (μ\c') c K (0, j)` at every `K`
   (stable K-threshold respected on both sides).  Proof:
   strict-hook localization — the GNW walk from `(0, j)` stays
   entirely in the region `R_j := {(r, s) ∈ μ : s ≥ j}`, and `R_j`
   contains no cell of row `c'.1` (since `c'` is the row-`c'.1`
   corner so `rowLen μ c'.1 = c'.2 + 1 ≤ j`) and no cell of column
   `c'.2` (since `j > c'.2`), hence removing `c'` does not modify
   any hook length seen by the recursion.

2. **(S71-b) Off-spine non-c-arm residual vanishing identity
   (conjecture, verified on 7 diagrams).**  For any off-spine cell
   `x ∈ (μ\c').cells` with `x.1 ≠ c'.1`, `x.2 ≠ c'.2`, and NOT in
   the c-arm row-0 region (i.e., NOT (`x.1 = 0` ∧ `c'.2 < x.2 ≤ c.2`)):

   ```
   gnwProb μ c (h_μ x) x · (h_d − 1)²  =  gnwProb (μ\c') c (h_(μ\c') x) x · h_d · (h_d − 2).
   ```

   Equivalently (using (★)'s algebra `(h_d−1)² − h_d(h_d−2) = 1`):

   ```
   pμ(x)  =  h_d · (h_d − 2) · Δp(x)            (★★)
   ```

   where `pμ(x) := gnwProb μ c K x`, `pν(x) := gnwProb (μ\c') c K x`,
   `Δp(x) := pν(x) − pμ(x)`, and the identity holds at any stable
   `K ≥ max(h_μ(x), h_(μ\c')(x))`.

3. **F_side_identity_aligned decomposition for case-1, c.1=0.**
   Combining S57.5's range-reduction, (S70)'s (★) for c'-column,
   (S71-a)'s c-arm row-0 `Δp = 0`, and (S71-b)'s (★★) for the
   non-c-arm off-spine residual vanishing, the unfiltered
   `F_side_identity_aligned` for case-1 c.1=0 reduces algebraically
   to the single equation

   ```
   ∑_{c'.2 < j ≤ c.2} pμ(0, j)  =  h_d (h_d − 2) · Δp(0, c'.2) − pμ(0, c'.2)        (S71-Σ)
   ```

   which is exactly the negation of (★)'s c'-column closed form.
   Hence the case-1 c.1=0 sub-instance of `F_side_identity_aligned`
   is *equivalent* — modulo (S71-a) and (S71-b) — to the
   conjunction "(S71-Σ) holds".  (S71-Σ) is verified on all seven
   S62–S70 test diagrams; whether it can be proved without
   invoking the global `F_side_identity` is the same open question
   as (S71-b)'s direct combinatorial proof.

## Why we expected S71

S70 (`sessions/2026-05-12-s09.md`) closed the c'-column residual
in case-1 c.1=0 to the closed form

```
(★)   c'-col residual  =  pμ(0)  −  h_d (h_d − 2) · Δp(0)
```

where `pμ(0) := gnwProb μ c K (0, c'.2)` and
`Δp(0) := pν(0) − pμ(0)`.  In the (5,3,2) test, the off-spine
residual was observed to be `+8/3 = −(c'-col residual)`, and
S70's §"Implication for `F_side_identity_aligned`'s proof"
flagged the off-spine residual as the next open closed-form:

> the off-spine residual MUST equal the NEGATION of the
> c'-column residual (the c'-row residual is 0 by S57.5's case-1
> vanishing combined with corner-classification), so an algebraic
> identity dual to (★) — applied to off-spine cells `(0, j)` with
> `c'.2 < j ≤ c.2` — should yield the same closed-form.
> **Recommended S71** to nail that algebraic identity for off-spine.

This session executes S70's recommendation.  The decomposition
turned out subtler than a single algebraic identity: the
off-spine cell category splits into two structurally distinct
sub-regions, each carrying its own closed form:

* **c-arm row-0 cells** `(0, j)` with `c'.2 < j ≤ c.2`: pointwise
  `pμ = pν` (`Δp = 0`), so the residual reduces to
  `pμ(0, j) · 1 = pμ(0, j)`.
* **Non-c-arm off-spine cells**: `pμ = h_d(h_d−2) · Δp`, so the
  residual is identically `0`.

(S71-a) is **provable** via strict-hook localization (§1 below).
(S71-b) is verified on all 7 diagrams; a direct combinatorial
proof remains open (§2 below).

## §1 — (S71-a) `Δp = 0` on c-arm row 0 cells

### 1.1 Statement

**Claim (S71-a).** Let `μ` be a Young diagram with two distinct
corners `c`, `c'` satisfying case-1 `c.1 < c'.1` and `c'.2 < c.2`,
and assume `c.1 = 0`.  Let `j` satisfy `c'.2 < j ≤ c.2`.  Then
at every `K`,

```
gnwProb μ c K (0, j)  =  gnwProb (μ\c') c K (0, j).
```

### 1.2 Strict-hook localization argument

Let `R_j := {(r, s) ∈ μ : s ≥ j}` — the "right-of-column-`j−1`"
subdiagram.  Two observations.

* **R_j contains no cell of row `c'.1`**:  `c'` is a corner of
  `μ` with `c' = (c'.1, c'.2)`, so `rowLen μ c'.1 = c'.2 + 1`,
  and the cells of row `c'.1` are `(c'.1, 0), …, (c'.1, c'.2)` —
  all with column `≤ c'.2 < j`.  So no row-`c'.1` cell has column
  `≥ j`.

* **R_j contains no cell of column `c'.2`**:  trivially, every cell
  in `R_j` has column `≥ j > c'.2`.

Hence every cell of `R_j` is "off-spine" in the sense of S57.1 / S57.4
(off `c'`'s row and column).  By S57.1's
`hookLength_invariant_off_spine_of_c'` (Helpers.lean line ~14588) and
S57.4's `isCorner_invariant_off_spine_of_c'` (line ~14775), every cell
of `R_j` has the same hook length and the same "is-a-corner" status in
`μ` and in `μ\c'`.

**Strict-hook stays inside `R_j`.**  The strict hook of any
`(r, s) ∈ R_j` is the union of

* arm: cells `(r, s')` with `s < s' ≤ rowEnd μ r`; all in row `r`
  with column `≥ s+1 > s ≥ j`, hence in `R_j`;
* leg: cells `(r', s)` with `r < r' ≤ colEnd μ s`; all in column
  `s ≥ j`, hence in `R_j`.

By S57.1's `strictHookCells_invariant_off_spine_of_c'`
(line ~14616), restricted to cells of `R_j`, the strict hook in
`μ` and in `μ\c'` coincide as sets, and their cardinalities agree.

### 1.3 Induction on K

Recall the GNW recurrence (Helpers.lean line 14385 / `gnwProb` def):

```
gnwProb μ c (K+1) x
  = if x = c then 1
    else if isCorner μ x then 0
    else (1 / (strictHookCells μ x).card) · ∑_{y ∈ strictHookCells μ x} gnwProb μ c K y
```

(Base case `K = 0` returns `1` if `x = c`, else `0`.)

**Induction hypothesis (IH).** For every cell `y ∈ R_j` and every
`K' ≤ K`, `gnwProb μ c K' y = gnwProb (μ\c') c K' y`.

**Inductive step at `x = (0, j)`** (and at every `(r, s) ∈ R_j` by
the same argument):

* If `x = c`: case `c.1 = 0` and `j = c.2` (note `j ≤ c.2`, and `j = c.2`
  hits `x = c`).  Both sides return `1`.
* If `isCorner μ x` (and `x ≠ c`): then by S57.4's invariance also
  `isCorner (μ\c') x`, so both sides return `0`.
* Otherwise: both sides compute uniform averages over the **same**
  strict-hook set (by §1.2's invariance), and every cell of that set
  lies in `R_j` (by the arm/leg argument above), so by IH the
  per-cell values agree, and the averages coincide.

The recursion's argument-cell `(0, j)` lies in `R_j` (trivially:
column `j ≥ j`).  So the induction at `(0, j)` closes.

For the IH at `K+1` to apply, we need the IH to hold at every
`y ∈ R_j` — which is itself an induction on cell depth, but the
strict-hook recursion is well-founded (each step decreases the cell
to a strictly-larger-row/column neighbor), and the base case
(corner cells of `R_j`) follows from S57.4's invariance.

Therefore `gnwProb μ c K (0, j) = gnwProb (μ\c') c K (0, j)` at every
`K`, completing (S71-a).  ∎

### 2.3 Sub-regions of non-c-arm off-spine

(★★)'s right-hand side `h_d(h_d−2) · Δp(x)` is non-trivial when
`Δp ≠ 0`.  The verification reveals two qualitatively distinct
sub-regions:

* **Walk-vanishing non-c-arm off-spine.**  Cells where
  `pμ = pν = 0`: (★★) reduces to `0 = h_d(h_d−2) · 0`, trivial.
  Examples: `(1,0)`, `(1,2)`, `(2,0)`, all `(1,*)`/`(2,*)`/etc.
  cells whose strict-hook descendants are corners ≠ c.  Confirmed
  by S69's "walk-vanishing" classifier and S57.6 prep 1's
  `strictHookCells_off_spine_class_at_c'` (Helpers.lean ~15243):
  for off-spine cells with `x.1 ≥ 1` and `x.2 < c.2`, both
  walks reach only corners ≠ c.

* **Walk-non-vanishing non-c-arm off-spine.**  Cells with
  `pμ, pν > 0` and `Δp > 0`: (★★) becomes the *nontrivial*
  ratio identity `pμ(x)/pν(x) = h_d(h_d−2)/(h_d−1)²`.  These
  are the cells `(0, j)` with `0 ≤ j < c'.2` — i.e., row-0
  cells to the *left* of c'-column.

  Examples seen in the seven tests:
  - `(0,0)` on every diagram with `c'.2 ≥ 1` and `c.1 = 0`,
  - `(0,1)` on `(4,3)` where `c'.2 = 2`.

  On `(4,3,2)`, the cell `(0,0)`'s ratio is
  `(3/8)/(2/5) = 15/16 = h_d(h_d−2)/(h_d−1)² = 15/16` ✓.
  On `(5,3,2)`, `(0,0)`'s ratio is
  `(8/15)/(5/9) = 72/75 = 24/25 = h_d(h_d−2)/(h_d−1)²` ✓.
  On `(4,2)`, `(0,0)`'s ratio is `(2/3)/(3/4) = 8/9 = h_d(h_d−2)/(h_d−1)²` ✓.

### 2.4 Toward a proof of (S71-b)

Three approaches.

**A. Direct strict-hook recursion.**  For walk-non-vanishing
non-c-arm cells `(0, j)` with `j < c'.2`, the strict hook in `μ`
includes cells `(0, k)` with `j < k`.  Among these, the cells with
`c'.2 < k ≤ c.2` are c-arm row-0 (Δp = 0 by S71-a), the cell
`(0, c'.2)` is on c'-column (residual closed by (★)), the cells
`(0, k)` with `j < k < c'.2` are non-c-arm off-spine (the
inductive case for (★★) itself), and the leg cells `(r, j)` with
`r ≥ 1` reach into rows that may include `c'.1`.

The cleanest decomposition: split `(0, j)`'s strict-hook recursion
along the four classes from S57.0's plan (A/B/C/D = off-spine /
off-arm-of-c / arm-of-c' / leg-of-c'), apply (S71-a), (★), and
inductive (★★) on the appropriate sub-hooks, and discharge the
recurrence in one step.  Estimated complexity: ~80–150 lines Lean
once the supporting infrastructure is in place.

**B. Indirect — via `F_side_identity_aligned` global**:  (★★) for
walk-non-vanishing cells follows from the *global* F-side identity
combined with (S71-a), (★), and walk-vanishing.  But this is
circular for the S57.7 proof: we are trying to prove the global
identity, not assume it.

**C. Localization & change-of-shape.**  For `(0, j)` with `j < c'.2`,
both `pμ(0, j)` and `pν(0, j)` are independent of the cells in
column `c'.2` past row `0` (those cells' strict-hook contributions
are filtered by reaching `c = (0, c.2)`).  An explicit
`pμ = h_d(h_d−2) · Δp` recurrence — viewing `Δp` as the
"corrective probability mass concentrated on column c'.2 entries
to be removed" — may be amenable to a generating-function argument
(GNW's hook-content polynomial framework, knowledge.md §38).

Approach **A** is the recommended route for S72+.  Approach **C**
is the natural setting for a future generating-function recasting
(state.md "Alternative (deferred): a deterministic weighted-path
recasting of GNW…", line ~1070).

## §3 — Combined F_side_identity_aligned decomposition

### 3.1 The full decomposition (case 1, c.1 = 0)

For case 1 (`0 = c.1 < c'.1`, `c'.2 < c.2`):

```
F_side_identity_aligned
  ⇔  ∑_{x ∈ (μ\c').cells} pμ(x)·(h_d−1)² = ∑_{x ∈ (μ\c').cells} pν(x)·h_d·(h_d−2)
  ⇔  ∑ [pμ(x)·(h_d−1)² − pν(x)·h_d·(h_d−2)]  =  0
  ⇔  ∑ [pμ(x) − h_d(h_d−2)·Δp(x)]  =  0                         (using (h_d−1)² = h_d(h_d−2)+1)
```

Partition `(μ\c').cells` into four disjoint regions:

* **c'-row** = `{(c'.1, s) : s ∈ rowLen(μ\c') c'.1}` — sum vanishes
  by S57.3a's per-cell `gnwProb_zero_of_row_eq_c'_case1` (which
  gives `pμ(c'.1, s) = pν(c'.1, s) = 0` for all such cells in
  case-1's `c.1 < c'.1` regime; the only cell with `pμ > 0` would
  be `c` itself, but `c.1 = 0 < c'.1` so `c` is not on this row).
  Contribution: `0`.

* **c'-column on `r ∈ range c'.1`** = `{(r, c'.2) : 0 ≤ r < c'.1}`
  — closed form by (★): `pμ(0, c'.2) − h_d(h_d−2) · Δp(0, c'.2)`
  (S57.5's reduction collapses `r ∈ range c'.1` to `r ∈ range 1 = {0}`
  for `c.1 = 0`).

* **c-arm row 0** = `{(0, j) : c'.2 < j ≤ c.2}` — pointwise `Δp = 0`
  by (S71-a), so contribution per cell is `pμ(0, j)`.  Sum:
  `∑_{c'.2 < j ≤ c.2} pμ(0, j)`.

* **Non-c-arm off-spine** = everything else — pointwise residual
  vanishes by (S71-b) (conjecture, verified on 7 diagrams).
  Contribution: `0`.

Equating to zero:

```
0  +  [pμ(0, c'.2) − h_d(h_d−2) · Δp(0, c'.2)]  +  ∑_{c'.2 < j ≤ c.2} pμ(0, j)  +  0  =  0
```

which rearranges to

```
∑_{c'.2 < j ≤ c.2} pμ(0, j)  =  h_d(h_d−2) · Δp(0, c'.2)  −  pμ(0, c'.2)            (S71-Σ)
```

### 3.2 Cross-test verification of (S71-Σ)

For each test diagram, LHS := `∑_{c'.2 < j ≤ c.2} pμ(0, j)` and RHS :=
