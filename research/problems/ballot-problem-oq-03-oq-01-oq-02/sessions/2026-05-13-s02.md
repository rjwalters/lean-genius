## §5 — Structural results

### 5.1 Δh(i) = 1 on column c'.2 for 0 ≤ i ≤ c.1

**Claim.** `h_μ(i, c'.2) − h_ν(i, c'.2) = 1` for every `0 ≤ i ≤ c.1`.

**Proof.**  Hook length at `x = (i, c'.2)` decomposes:
`h(x) = (arm) + (leg) + 1` where arm and leg refer to lengths in the
respective shape.

* **Arm at `(i, c'.2)`** in μ vs ν: arm = `{(i, k) : c'.2 < k ≤ rowEnd i}`.
  Removing `c' = (c'.1, c'.2)` only affects row `c'.1`; for `i ≤ c.1
  < c'.1`, row `i` has the same length in μ and ν.  Arms agree.

* **Leg at `(i, c'.2)`** in μ vs ν: leg = `{(r, c'.2) : i < r ≤ colEnd c'.2}`.
  In μ, `colEnd_μ c'.2 = c'.1` (row c'.1 has length c'.2 + 1, so its
  column-c'.2 cell exists).  In ν, `colEnd_ν c'.2 = c'.1 − 1` (row
  c'.1 of ν has length c'.2, so its column-c'.2 cell is gone — that
  was c' itself).  So `leg_μ count = c'.1 − i`, `leg_ν count = c'.1 − 1 − i`.
  Difference: `Δ(leg count) = 1`.

* Combined: `Δh = 0 (arm) + 1 (leg) + 0 = 1`.  ∎

**Numerical check.** Δh = 1 across all rows on column 0 in both test
diagrams (§3.2, §4.2 tables).  ✓

For the c.1 = 0 specialization: Δh = 1 at row 0 gives
`h_μ(0, c'.2) − 1 = h_ν(0, c'.2)`, i.e., `h_d − 1 = h_ν(0, c'.2)` and
`h_d − 2 = h_ν(0, c'.2) − 1`.  This matches S72's notation in §5.1.

### 5.2 (Anchor-c.1) from GNW recurrence + (S71-a)' at row c.1

**Claim.** For case-1 (general c.1 ≥ 0):

```
pμ(c.1, c'.2) · (h_μ(c.1, c'.2) − 1)  =  pν(c.1, c'.2) · (h_ν(c.1, c'.2) − 1)
                                                                  (Anchor-c.1)
```

**Proof.**  Apply the GNW recurrence at `(c.1, c'.2)` in both μ and
ν.  In μ:

```
pμ(c.1, c'.2) · (h_μ(c.1, c'.2) − 1)
   =  Σ_{y ∈ strictHook_μ (c.1, c'.2)} pμ(y)
   =  [arm: Σ_{c'.2 < k ≤ rowEnd_μ c.1} pμ(c.1, k)]
      + [leg: Σ_{c.1 < r ≤ c'.1} pμ(r, c'.2)]            (Y)
```

By §4.6 walk-vanishing (general statement), `pμ(r, c'.2) = 0` for
`r > c.1`.  Hence the leg sum vanishes:

```
pμ(c.1, c'.2) · (h_μ(c.1, c'.2) − 1) = Σ_{c'.2 < k ≤ rowEnd_μ c.1} pμ(c.1, k)
                                                                   (R_μ@row c.1)
```

By the same argument in ν (where `colEnd_ν c'.2 = c'.1 − 1`, still
`> c.1` since `c'.1 > c.1`):

```
pν(c.1, c'.2) · (h_ν(c.1, c'.2) − 1) = Σ_{c'.2 < k ≤ rowEnd_ν c.1} pν(c.1, k)
                                                                   (R_ν@row c.1)
```

Both row-c.1 arms are identical in μ and ν (only row c'.1 is shortened
by c' removal; row c.1 with `c.1 < c'.1` is preserved).  And by an
**(S71-a)' generalization** (the strict-hook localization of S71 §1.2
applied at row c.1 instead of row 0), `pμ(c.1, k) = pν(c.1, k)` for
all c-arm-row-c.1 cells `(c.1, k)` with `c'.2 < k ≤ c.2`.

**(S71-a)' proof sketch.**  S71's proof restricted the GNW walk from
`(0, j)` with `j > c'.2` to the rectangle `R_j := {(r, s) ∈ μ : s ≥ j}`,
which excludes row c'.1 (since `rowLen μ c'.1 = c'.2 + 1 ≤ j`) and
column c'.2 (since `s ≥ j > c'.2`).  The same argument with `(c.1, k)`
in place of `(0, j)`: `R_k := {(r, s) ∈ μ : s ≥ k > c'.2}` excludes
row c'.1 (length `c'.2 + 1 ≤ k`) and column c'.2.  By S57.1's
`hookLength_invariant_off_spine_of_c'` + S57.4's
`isCorner_invariant_off_spine_of_c'`, the recursion in μ and ν
coincide on `R_k`, so `pμ(c.1, k) = pν(c.1, k)`.  Note: c is a corner
of both μ and ν, and the walk from `(c.1, k)` with `k > c'.2` can
reach c at `(c.1, c.2)` (since both row indices = c.1, walk traverses
right along row c.1).

Therefore:

```
pμ(c.1, c'.2) · (h_μ(c.1, c'.2) − 1) = Σ_{c'.2 < k ≤ rowEnd_μ c.1} pμ(c.1, k)
                                     = Σ_{c'.2 < k ≤ rowEnd_ν c.1} pν(c.1, k)
                                     = pν(c.1, c'.2) · (h_ν(c.1, c'.2) − 1)        ∎
```

The proof generalizes S72 §5.1 verbatim from row 0 to row c.1; the
only changes are the walk-vanishing rationale (now for r > c.1
instead of r ≥ 1) and the (S71-a)' generalization (now at row c.1
instead of row 0).  S71-a was already stated for general row 0; the
generalization is verbatim once `c.1 = 0` is removed as a hypothesis.

(For our two test diagrams: §3.6 verifies on (3,2,2,1) at i = c.1 = 2;
§4.7 verifies on (3,2,1,1,1) at i = c.1 = 1.)

### 5.3 (GenEq-Refined)_i: the downward cascade

**Claim.**  For case-1 and every `0 ≤ i ≤ c.1`:

```
α_i  =  δ_i · (h_ν(i, c'.2) − 1)  −  Σ_{r = i+1}^{c.1} δ_r       (GenEq-Refined)_i
```

**Proof.**  Apply GNW at `(i, c'.2)` in both μ and ν (no walk-vanishing
yet — we're at `i ≤ c.1`):

```
α_i · (h_μ(i, c'.2) − 1) = arm-μ-sum + leg-μ-sum                     (Y_μ)
β_i · (h_ν(i, c'.2) − 1) = arm-ν-sum + leg-ν-sum                     (Y_ν)
```

* arm-μ-sum = arm-ν-sum, by the (S71-a)' generalization at row i
  (same argument as §5.2, but at row i ≤ c.1 instead of i = c.1).
  Note: for `i < c.1`, the cells `(i, k)` with `c'.2 < k ≤ rowEnd_μ i`
  are NOT in c-arm (which is row c.1); they're row-i cells with
  `k > c'.2`.  But the strict-hook localization argument still applies:
  walk from `(i, k)` stays in `R_k = {(r, s) : s ≥ k > c'.2}` which
  excludes row c'.1 and column c'.2.  So pμ(i, k) = pν(i, k) for all
  i and all k > c'.2 (provided c is reachable from (i, k), which
  holds since c = (c.1, c.2) with c.2 > c'.2 ≥ k or k ≤ c.2; the
  walk from (i, k) goes "right and down" and can reach (c.1, c.2)).
  
* leg-μ-sum = Σ_{i < r ≤ c'.1} α_r = Σ_{i < r ≤ c.1} α_r  +  Σ_{c.1 < r ≤ c'.1} α_r.
* leg-ν-sum = Σ_{i < r ≤ c'.1 − 1} β_r = Σ_{i < r ≤ c.1} β_r  +  Σ_{c.1 < r ≤ c'.1 − 1} β_r.

By §4.6 walk-vanishing: α_r = 0 for r > c.1 (in μ), and β_r = 0 for
r > c.1 (in ν).  Hence the "deep" cross-terms vanish:

```
leg-μ-sum = Σ_{i < r ≤ c.1} α_r
leg-ν-sum = Σ_{i < r ≤ c.1} β_r
```

Subtract (Y_μ) − (Y_ν):

```
α_i · (h_μ(i, c'.2) − 1) − β_i · (h_ν(i, c'.2) − 1)
   = [arm-μ-sum − arm-ν-sum]                    (= 0 by (S71-a)')
   + [leg-μ-sum − leg-ν-sum]
   = − Σ_{i < r ≤ c.1} δ_r                                            (S)
```

Apply Δh(i) = 1 (§5.1) and α_i = β_i − δ_i:

```
α_i · (h_μ(i, c'.2) − 1) − β_i · (h_ν(i, c'.2) − 1)
   = α_i · (h_ν(i, c'.2) − 1 + 1) − (α_i + δ_i) · (h_ν(i, c'.2) − 1)
   = α_i − δ_i · (h_ν(i, c'.2) − 1).
```

So (S) becomes:

```
α_i − δ_i · (h_ν(i, c'.2) − 1) = − Σ_{i < r ≤ c.1} δ_r
α_i = δ_i · (h_ν(i, c'.2) − 1) − Σ_{r = i+1}^{c.1} δ_r       ∎
```

(GenEq-Refined)_i identifies `c.1 + 1` linear identities relating the
unknowns α_i and δ_i (for `0 ≤ i ≤ c.1`).

### 5.4 Equivalent S_i = δ_i · (h_ν(i, c'.2) − 1) form

Let `S_i := α_i + Σ_{r = i+1}^{c.1} δ_r`.  Then (GenEq-Refined)_i
becomes:

```
S_i  =  δ_i · (h_ν(i, c'.2) − 1)         (S-form)
```

This is a **pointwise** identity per row: `S_i / (h_ν(i, c'.2) − 1) =
δ_i` for `h_ν(i, c'.2) ≥ 2` (which holds for `i < c'.1`).

Checks:

* Diagram 1 (3,2,2,1), c = (2,1), c' = (3,0):
  | i | S_i = α_i + Σ_{>i} δ_r | h_ν(i, 0) − 1 | δ_i | S_i / (h_ν−1) |
  |---|------------------------|----------------|-----|----------------|
  | 0 | 1/3 + 1 = 4/3          | 4              | 1/3 | 4/3 / 4 = 1/3   ✓ |
  | 1 | 1/2 + 1/2 = 1          | 2              | 1/2 | 1/2  ✓          |
  | 2 | 1/2 + 0 = 1/2          | 1              | 1/2 | 1/2  ✓          |

* Diagram 2 (3,2,1,1,1), c = (1,1), c' = (4,0):
  | i | S_i              | h_ν(i, 0) − 1 | δ_i  | S_i / (h_ν−1) |
  |---|------------------|----------------|------|----------------|
  | 0 | 1/8 + 1/12 = 5/24 | 5              | 1/24 | 5/24 / 5 = 1/24 ✓ |
  | 1 | 1/4 + 0 = 1/4    | 3              | 1/12 | 1/4 / 3 = 1/12  ✓ |

Both diagrams confirm S-form.  The S-form will be useful in §6 for
casting the F_side_identity_aligned closure as an explicit linear

## §6 — Implications for F_side_identity_aligned case-1 c.1 ≥ 1

### 6.1 What F_side_identity_aligned demands at the c'-column

For case-1, S57.5's `sum_gnwProb_leg_of_c'_reduce_case1` (PR #17865)
collapses the c'-column F-side sum to `range (c.1 + 1)`:

```
∑_{r = 0}^{c.1} [α_r · ZW_μ(r) − β_r · ZW_ν(r)]               (FSI-c'-col)
```

where `ZW_μ(r)`, `ZW_ν(r)` are hook-product-weight coefficients
specific to the F-side identity (see S52
`hookProd_doubleRemove_factor` and S57.5).  In S70's c.1 = 0
specialization, ZW_μ(0) = `(h_d − 1)²` and ZW_ν(0) = `h_d (h_d − 2)`
where `h_d = h_μ(0, c'.2)`.  For c.1 ≥ 1, ZW_μ(r), ZW_ν(r) need to be
read off Helpers.lean's S57.5 statement at line ~14550 — deferred to
S74+ inspection.

### 6.2 What (Anchor-c.1) + (GenEq-Refined) buys us

(Anchor-c.1) is a single equation relating `α_{c.1}` to `β_{c.1}`
via fixed hook coefficients:

```
α_{c.1} · (h_μ(c.1, c'.2) − 1) = β_{c.1} · (h_ν(c.1, c'.2) − 1)
α_{c.1} · h_ν(c.1, c'.2) = β_{c.1} · (h_ν(c.1, c'.2) − 1)         (using Δh = 1)
```

(GenEq-Refined) is `c.1 + 1` such equations cascading down to row 0.

In total: `c.1 + 1` linear equations on the `2·(c.1 + 1)` unknowns
`{α_i, β_i}_{0 ≤ i ≤ c.1}`.  The system is **under-determined** by
exactly `c.1 + 1` degrees of freedom; these are pinned down by the
remaining GNW recurrences within each row (i.e., the arm-side
recurrences at each `(i, c'.2)`).

### 6.3 Closure strategy

For the c.1 ≥ 1 closure, one needs to:

1. **Read S57.5's `ZW_μ`, `ZW_ν` explicitly** at the c'-column reduction
   point.  This pins down (FSI-c'-col) algebraically.
2. **Use (GenEq-Refined) + (Anchor-c.1) + (S71-a)' + walk-vanishing**
   to evaluate (FSI-c'-col) in closed form (or as a `ring`-discharge
   given the hook-length identities).
3. **Combine with the other F_side_identity_aligned pieces** —
   c-arm row c.1, c'-row, non-c-arm off-spine — to close the case-1
   c.1 ≥ 1 identity in Lean.

**The (S71-a) generalization is non-trivial only at the strict-hook
localization step**, which the present session noted is verbatim
from S71 §1.2 with row index `c.1` instead of `0`.  Lean cost
estimate: same as S71's ~40-70 LOC.

**Lean cost estimate for c.1 ≥ 1 closure (revised from S72's ~120-195
LOC for c.1 = 0):**

* (S71-r) c'-row vanishing: ~10 LOC (S57.3a — invariant under c.1).
* (S71-a)' c-arm row c.1 pμ = pν: ~40-70 LOC (verbatim from S71 §1.2
  at row c.1 instead of 0).

  reduction + (GenEq-Refined) cascade + Δh = 1 + ring).  The

### 6.4 Comparison with case-2 c.2 ≥ 1

By S58 `transpose-equivariance` (Helpers.lean line ~15205), case-2
