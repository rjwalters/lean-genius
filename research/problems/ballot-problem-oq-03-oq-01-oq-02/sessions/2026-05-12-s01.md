### `sum_gnwProb_leg_of_c'_reduce_case1` (~17 lines, sorry-free)

```
private lemma sum_gnwProb_leg_of_c'_reduce_case1
    {μ : YoungDiagram} {c c' : ℕ × ℕ}
    (hc1 : c.1 < c'.1) (K : ℕ) :
    ∑ r ∈ Finset.range c'.1, gnwProb μ c K (r, c'.2) =
      ∑ r ∈ Finset.range (c.1 + 1), gnwProb μ c K (r, c'.2)
```

**Proof.** Split `Finset.range c'.1 = Finset.Ico 0 c'.1` into
`Ico 0 (c.1 + 1) ∪ Ico (c.1 + 1) c'.1` via
`Finset.sum_Ico_consecutive`.  The high-row block
`Ico (c.1 + 1) c'.1` vanishes pointwise: for `r ≥ c.1 + 1`, we have
`c.1 < r = (r, c'.2).1`, so `gnwProb_unreachable_zero` on the `Or.inl`
disjunct gives `gnwProb μ c K (r, c'.2) = 0`.  Closing with
`Finset.sum_eq_zero` and `add_zero` leaves the low-row block
`Ico 0 (c.1 + 1) = range (c.1 + 1)`.

### `sum_gnwProb_arm_of_c'_reduce_case2` (~17 lines, sorry-free)

```
private lemma sum_gnwProb_arm_of_c'_reduce_case2
    {μ : YoungDiagram} {c c' : ℕ × ℕ}
    (hc2 : c.2 < c'.2) (K : ℕ) :
    ∑ s ∈ Finset.range c'.2, gnwProb μ c K (c'.1, s) =
      ∑ s ∈ Finset.range (c.2 + 1), gnwProb μ c K (c'.1, s)
```

**Proof.** Mirror of the case-1 leg-of-c' proof under the
`gnwProb_transpose` symmetry (S58).  Splits via
`Finset.sum_Ico_consecutive` at `c.2 + 1`; the high-column block
vanishes via `gnwProb_unreachable_zero`'s `Or.inr` disjunct
(`c.2 < s = (c'.1, s).2` for `s ≥ c.2 + 1`).  Given directly rather
than via transpose for implementation simplicity — the transpose
derivation requires shuffling `Prod.swap` through the sum
reindexing, while the direct proof is a structural mirror.

## Why these residuals are tight

For the case-1 leg-of-c' residual `r ∈ range (c.1 + 1)`, the cells
`(r, c'.2)` with `r ≤ c.1` have:
* `x.1 = r ≤ c.1` (so `c.1 < x.1` fails — `Or.inl` does not fire).
* `x.2 = c'.2 < c.2` in case 1 (since case 1 ≡ `c.1 < c'.1 ∧ c'.2 < c.2`
  by `distinct_corners_dichotomy`), so `c.2 < x.2` fails — `Or.inr`
  does not fire either.

Hence `gnwProb_unreachable_zero` does *not* give pointwise vanishing
for any `r ≤ c.1`.  Worse, the cells are *genuinely reachable* from
`c` (via the walk `c → (c.1, c.2) → (c.1, c'.2) → … → (r, c'.2)` or
similar): the residual is non-trivially nonzero.  At `r = c.1` the
cell is the **doubly-affected cell** `d = (c.1, c'.2)` of case 1
(`min c.1 c'.1 = c.1`, `min c.2 c'.2 = c'.2`).

By the transpose mirror, the case-2 arm-of-c' residual
`s ∈ range (c.2 + 1)` is similarly tight, with the doubly-affected
cell `d = (c'.1, c.2)` of case 2 appearing at `s = c.2`.

## Role in the S57.0 plan

The four S57.3 + S57.5 lemmas together discharge the *Finset-level
geometry* of the cell partition: arm-of-c' and leg-of-c' sums on
either side of the case-1/case-2 dichotomy reduce to either zero
or a bounded residual `range (c.1 + 1)` / `range (c.2 + 1)`.

The remaining work for the joint K-induction in
`F_side_identity_aligned` splits into two genuinely-comparison
tasks:

1. **(S6) Off-spine pointwise integrand identity** at every K.
   Modulo S57.4's `gnwProb_succ_eq_off_spine_of_c'` (the inductive
   step) and the trivial K=0 base, this reduces to handling the
   `y` in `strictHookCells μ x.1 x.2` that *cross* `c'`'s spine
   (rows/cols containing `c'`).  S57.6 target.

2. **(S2)/(S3) Live arm/leg pointwise integrand identity** at the
   `range (c.1 + 1)` / `range (c.2 + 1)` residual cells.  Each
   residual contains the doubly-affected cell `d` plus `c.1` (resp.
   `c.2`) "below-`c`" cells where genuine arm/leg comparison
   between `gnwProb μ` and `gnwProb (μ\c')` is required.  S57.7
   target — likely needs a per-cell `δ_arm` correction term.

After S57.6 + S57.7, the joint assembly (S57.8) discharges
`F_side_identity_aligned` and promotes the entry to **verified**.
