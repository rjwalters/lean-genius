## §1 — Setup and notation

### 1.1 Residual functional

For case-1 (`c.1 < c'.1`, `c'.2 < c.2`) with `c.1 = 0`:

```
R(x) := pμ(x) · (h_d − 1)²  −  pν(x) · h_d · (h_d − 2)
```

where `pμ(x) := gnwProb μ c (h_μ x) x` and `pν(x) := gnwProb (μ\c') c
(h_(μ\c') x) x` are stable (post-`K ≥ max(h_μ x, h_(μ\c') x)`) values,
and `h_d := h_μ(0, c'.2) = hookLength μ 0 c'.2`.

`F_side_identity_aligned` (LHS−RHS) for case 1 sums to
`Σ_{x ∈ (μ\c').cells} R(x)`, after S57.5's range reduction collapses
the c'-column sum to crossings with `r < c.1 + 1 = {0}`.  The
"residual" terminology of S70 §2 corresponds to `R(0, c'.2)`.

### 1.2 (★★) restated in R-notation

### 1.3 Hook-length stability on j < c'.2

**Claim.**  For `j < c'.2`, `h_μ(0, j) = h_ν(0, j)`.

**Proof.**  Arm at `(0, j)`: cells `{(0, k) : j < k ≤ c.2}`.
Since `c.1 = 0`, the corner `c = (0, c.2)` of `μ` sits on row 0, so
removing `c' = (c'.1, c'.2)` with `c'.1 ≥ 1` (case 1) does not affect
row 0's length: `rowLen_ν 0 = rowLen_μ 0 = c.2 + 1`.  Arm length
agrees: `c.2 − j` in both shapes.

Leg at `(0, j)`: cells `{(r, j) : 1 ≤ r ≤ colEnd_μ j}`.  Row `c'.1`
contributes to `colLen_μ j` iff `c'.2 ≥ j+1` (since row `c'.1` of `μ`
has length `c'.2 + 1`).  Row `c'.1` contributes to `colLen_ν j` iff
`c'.2 ≥ j+1` (since row `c'.1` of `ν` has length `c'.2`, and
`length > j ⟺ length ≥ j+1 ⟺ c'.2 ≥ j+1`).  Wait — the predicate
for "row `c'.1` contributes to column `j` in `ν`" is "length of row
`c'.1` in `ν` is `> j`", i.e., `c'.2 > j`, i.e., `j < c'.2`.  The
predicate for "row `c'.1` contributes to column `j` in `μ`" is
"length of row `c'.1` in `μ` is `> j`", i.e., `c'.2 + 1 > j`, i.e.,
`j ≤ c'.2`.

For `j < c'.2`: both predicates hold (j < c'.2 ⟹ j ≤ c'.2). ✓
For `j = c'.2`: first predicate fails, second holds (so
`colLen_μ c'.2 = colLen_ν c'.2 + 1`, the well-known c'-column
hook-length deficit).

For all rows after c'.1: row `i` for `i > c'.1` has the SAME length
in `μ` and `ν` (removing the row-`c'.1` corner doesn't affect them).
So those rows contribute identically to `colLen_μ j` and
`colLen_ν j`.

For all rows before c'.1: row `i` for `i < c'.1` has the SAME length
in `μ` and `ν`.  Same as above.

Therefore for `j < c'.2`: `colLen_μ j = colLen_ν j`, and so
`h_μ(0, j) = h_ν(0, j)`.  ∎

### 1.4 Walk-vanishing of leg cells

**Claim.**  For any `j` and any `r ≥ 1`, if `(r, j) ∈ μ` then
`gnwProb μ c K (r, j) = 0` at every stable `K`.  Similarly in `ν`.

**Proof sketch.**  The GNW walk from cell `x` moves into the strict
hook `strictHookCells μ x` of `x`, which contains only cells with
the same row OR the same column as `x`, and strictly greater
column-or-row index.  Concretely: if `y ∈ strictHookCells μ x`, then
either `y.1 = x.1` and `y.2 > x.2` ("arm step"), or `y.2 = x.2` and
`y.1 > x.1` ("leg step").  In particular, `y.1 ≥ x.1`.

Hence at every step of the GNW walk from `x = (r, j)`, the row index
is non-decreasing.  Starting at row `r ≥ 1`, the walk cannot reach
row 0; in particular, it cannot reach `c = (0, c.2)` (which has row
0 since `c.1 = 0`).  By the GNW recurrence, walks that don't
terminate at `c` contribute 0 to `gnwProb μ c · ·`.  ∎

(This is essentially S69's "walk-vanishing" classifier and S57.6
prep 1's `strictHookCells_off_spine_class_at_c'` machinery applied
to leg cells.  See Helpers.lean ~15243 for the Lean infrastructure.)

**Corollary.**  Σ_{leg of (0, j)} R(r, j) = Σ_{leg} [pμ(r,j)·(h_d−1)²
− pν(r,j)·h_d(h_d−2)] = 0 since both factors of every summand are 0.

## §2 — Recurrence inheritance of R on row 0, `j < c'.2`

### 2.1 Recurrence for pμ(0, j), pν(0, j)

For `(0, j)` with `j < c'.2`, `(0, j) ≠ c` (since `c.2 > c'.2 > j`)
and `(0, j)` is not a corner of `μ` or `ν` (since arm-length
> 0 and column-cells continue past row 0 by §1.3).  So the GNW
recurrence gives, at stable `K`:

```
pμ(0, j) = (1 / [h_μ(0, j) − 1]) · ∑_{y ∈ strictHookCells μ (0,j)} pμ(y)
         = (1 / [h_j − 1])   · [ ∑_{arm} pμ(0, k) + ∑_{leg} pμ(r, j) ]
         = (1 / [h_j − 1])   · ∑_{k = j+1}^{c.2} pμ(0, k)               (by §1.4 walk-vanishing leg)
```

where `h_j := h_μ(0, j) = h_ν(0, j)`.  By the same reasoning:

```
pν(0, j) = (1 / [h_j − 1]) · ∑_{k = j+1}^{c.2} pν(0, k)
```

(Note: `(strictHookCells μ x).card = h_μ(x) − 1` since strict hook
excludes `x` itself.  See Helpers.lean line 14385 `gnwProb` def.)

### 2.2 Recurrence for R(0, j)

Linearity of `R = pμ · (h_d − 1)² − pν · h_d(h_d−2)` over the GNW
recurrence:

```
R(0, j) = (1 / [h_j − 1]) · ∑_{k = j+1}^{c.2} R(0, k)              (RR)
```

The denominator `h_j − 1 ≥ 1` (strict positivity by `h_j ≥ 2`, since
arm-length ≥ 1 from `c.2 > j`).

### 2.3 Three sub-arms of (RR)

Partition the arm `{k : j+1 ≤ k ≤ c.2}` into three classes:

* **(A) inductive WN:** `j+1 ≤ k < c'.2` — non-c-arm off-spine row-0
  walk-non-vanishing.  R(0, k) is the inductive case for (★★).
* **(B) c'-column:** `k = c'.2` — the c'-column cell at row 0.
  R(0, c'.2) is the (★) closed-form (S70).
* **(C) c-arm row-0:** `c'.2 < k ≤ c.2` — c-arm row-0 cells.  By
  (S71-a) Δp = 0, so `pν(0, k) = pμ(0, k)`, and

  ```
  R(0, k) = pμ(0, k) · (h_d − 1)² − pμ(0, k) · h_d · (h_d − 2)
          = pμ(0, k) · [(h_d − 1)² − h_d · (h_d − 2)]
          = pμ(0, k) · 1                                  (by (h_d−1)² − h_d(h_d−2) = 1)
          = pμ(0, k).
  ```

Hence (RR) rewrites as:

```
R(0, j) · (h_j − 1)
     =  ∑_{k = j+1}^{c'.2 − 1} R(0, k)                          (class A)
     +  R(0, c'.2)                                                (class B)
     +  ∑_{k = c'.2 + 1}^{c.2} pμ(0, k)                            (class C)
                                                                  (RR')
```

## §3 — Circularity computation

### 3.1 Base case of the induction

The proposed (S71-b) induction is **downward in j**: prove
`R(0, j) = 0` for `j = c'.2 − 1`, then `j = c'.2 − 2`, etc.,
terminating at `j = 0`.  (An upward induction `j = 0` first is
impossible because (RR') at `j = 0` references R(0, k) for k up to
c.2, hence requires knowledge of R(0, k) for larger k — backward
information that hasn't been computed yet.)

**Inductive base `j = c'.2 − 1`.**  Class A is empty (range
`j+1 ≤ k < c'.2 = j+1` is empty).  (RR') reduces to:

```
R(0, c'.2 − 1) · (h_{c'.2−1} − 1)
     =  R(0, c'.2)  +  ∑_{c'.2 < k ≤ c.2} pμ(0, k).         (RR''_0)
```

For (★★) at j = c'.2 − 1, we need `R(0, c'.2 − 1) = 0`.  Since
`h_{c'.2−1} − 1 > 0`, this is equivalent to:

```
R(0, c'.2) + ∑_{c'.2 < k ≤ c.2} pμ(0, k) = 0.                   (BC)
```

### 3.2 (BC) ≡ (S71-Σ)

S70's (★) computes `R(0, c'.2)`:

```
R(0, c'.2) = pμ(0, c'.2) · (h_d − 1)² − pν(0, c'.2) · h_d · (h_d − 2)
           = pμ(0, c'.2) · [(h_d − 1)² − h_d (h_d − 2)] − Δp(0, c'.2) · h_d (h_d − 2)
           = pμ(0, c'.2) − h_d (h_d − 2) · Δp(0, c'.2)         (★)
```

where `Δp(0, c'.2) := pν(0, c'.2) − pμ(0, c'.2)` and we use
`(h_d − 1)² = h_d (h_d − 2) + 1`.  This matches S70's (★) verbatim.

Substituting into (BC):

```
[pμ(0, c'.2) − h_d (h_d − 2) · Δp(0, c'.2)] + ∑_{c'.2 < k ≤ c.2} pμ(0, k) = 0
```

Rearranging:

```
∑_{c'.2 < k ≤ c.2} pμ(0, k) = h_d (h_d − 2) · Δp(0, c'.2) − pμ(0, c'.2)
```

— which is **exactly (S71-Σ)** of S71 §3.1.

### 3.3 (S71-Σ) ≡ F_side_identity_aligned case-1 c.1=0

S71 §3.1's sum-partition derives:

```
F_side_identity_aligned case-1 c.1=0
     ⟺   ∑_{x ∈ (μ\c').cells} R(x) = 0
     ⟺   [c'-row sum: 0] + [c'-col after S57.5: R(0, c'.2)]
          + [c-arm row 0: ∑_{c'.2<k≤c.2} pμ(0, k)]
          + [non-c-arm off-spine: ∑_{WV+WN} R(x)]
        = 0
```

Walk-vanishing non-c-arm off-spine contributes 0 trivially.
Therefore F_side_identity_aligned for case-1 c.1=0 is equivalent to:

```
R(0, c'.2) + ∑_{c'.2<k≤c.2} pμ(0, k) + ∑_{non-c-arm WN} R(x) = 0     (F)
```

Now: if (S71-b-WN) holds — i.e., `R(0, j) = 0` for all `j < c'.2` —
then the WN sum vanishes, and (F) reduces to (BC) = (S71-Σ).

Conversely: if (S71-Σ) holds, then (BC) holds, so (RR''_0) gives
`R(0, c'.2 − 1) = 0`.  For `j < c'.2 − 1`, (RR') with the IH
`R(0, k) = 0` for `j < k < c'.2` reduces to (BC):

```
R(0, j) · (h_j − 1) = 0 + R(0, c'.2) + ∑_{c'.2 < k ≤ c.2} pμ(0, k)
                    = R(0, c'.2) + c-arm row-0 pμ-sum
                    = 0        (by (S71-Σ) and (★))
```

so `R(0, j) = 0`.  By downward induction, (S71-b-WN) at every j < c'.2.

**Therefore:** `(S71-b-WN) ⟺ (S71-Σ) ⟺ F_side_identity_aligned
case-1 c.1=0`.

### 3.5 What "discharge in one step" doesn't say

S71 §2.4 Approach A's "discharge the recurrence in one step" wording
glosses over the base case.  Concretely: combining (RR') with
(S71-a), (★), and inductive (★★) leaves the **residual equation**

```
R(0, j) · (h_j − 1) = [WN-applied IH = 0] + R(0, c'.2) + c-arm row-0 pμ-sum
                    = (★) closed form + c-arm row-0 pμ-sum
                    = some-specific-rational-number depending on (μ, c, c').
```

For this to equal 0, we need exactly (S71-Σ).  The recurrence
*cannot* close (★★) at any single j without (S71-Σ) supplied as
external input.  In particular, "discharging" (★★) is not a local
algebraic identity (like `(h_d−1)² = h_d(h_d−2) + 1` powering (★))
but a *global* arithmetic fact about the sum
`Σ pμ(0, k)` over c-arm row 0 relative to the c'-column residual.

This is in stark contrast with S70's (★), which is a local identity
following from `(h_d − 1)² = h_d (h_d − 2) + 1` and is independent
of the diagram.

## §5 — Forward directions for (S71-Σ)

Three candidate routes to an *independent* proof of (S71-Σ) that
avoids circular invocation of F_side_identity_aligned.

### 5.1 Route I — Direct row-0 sub-walk recurrence

The sequence `pμ(0, c.2), pμ(0, c.2 − 1), …, pμ(0, 0)` satisfies the
linear recurrence (from §2.1):

```
pμ(0, j) · (h_μ(0, j) − 1)  =  ∑_{k = j+1}^{c.2} pμ(0, k)              (R_μ)
```

with boundary `pμ(0, c.2) = 1` (c.2 = c.2, the corner c).
Similarly for `pν` with `h_ν(0, j) − 1`:

```
pν(0, j) · (h_ν(0, j) − 1)  =  ∑_{k = j+1}^{c.2} pν(0, k)              (R_ν)
```

with boundary `pν(0, c.2) = 1` (since `c.2 > c'.2` so c is still a
corner of ν).

The recurrences differ only in the denominator factor at `j = c'.2`:
`h_μ(0, c'.2) − 1` versus `h_ν(0, c'.2) − 1`.  Specifically:

* For `j > c'.2` (c-arm row 0): `h_μ(0, j) = h_ν(0, j)` (Δp = 0 by
  S71-a, equivalently by `colLen` agreement on `j > c'.2` —
  removing c' doesn't affect column j for j > c'.2).
* For `j = c'.2`: `h_μ(0, c'.2) = h_d` while `h_ν(0, c'.2) = h_d − 1`
  (the row-`c'.1` cell is removed from column c'.2).
* For `j < c'.2`: `h_μ(0, j) = h_ν(0, j)` (§1.3 above).

So `pν` differs from `pμ` only in the recurrence step at `j = c'.2`,
where the divisor is 1 smaller.  This is a **single-perturbation
recurrence** structure.

**Goal of Route I:** express (S71-Σ) — equivalently
`Σ c-arm pμ + R(0, c'.2) = 0` — as a closed form in `h_d`, `c.2`,
`c'.2`, `colLen_μ k for k = 0..c.2` (the "row-0 hook profile"), via
algebraic manipulation of (R_μ) and (R_ν).

Concretely: the c-arm row-0 sum equals a quasi-telescoping sum from
(R_μ) iterated.  At `j = c'.2`:

```
pμ(0, c'.2) · (h_d − 1)  =  ∑_{c'.2 < k ≤ c.2} pμ(0, k)              (R_μ at j=c'.2)
```

So `Σ c-arm pμ = pμ(0, c'.2) · (h_d − 1)`.  ✓ cross-check on (5,3,2):
`pμ(0, 1) · 5 = (8/15) · 5 = 8/3` matches table's 8/3 ✓.  On (4,3,2):
`(3/8) · 4 = 3/2` ✓.

**(S71-Σ) becomes:**

```
pμ(0, c'.2) · (h_d − 1) = h_d (h_d − 2) · Δp(0, c'.2) − pμ(0, c'.2)
⟺ pμ(0, c'.2) · h_d = h_d (h_d − 2) · Δp(0, c'.2)
⟺ pμ(0, c'.2) = (h_d − 2) · Δp(0, c'.2)                                  (S71-Σ')
⟺ pμ(0, c'.2) = (h_d − 2) · (pν(0, c'.2) − pμ(0, c'.2))
⟺ pμ(0, c'.2) · (h_d − 1) = (h_d − 2) · pν(0, c'.2)                       (S71-Σ'')
```

The **dramatically simpler restatement (S71-Σ'')** says:

```
pμ(0, c'.2) · (h_μ(0, c'.2) − 1)  =  (h_ν(0, c'.2) − 1) · pν(0, c'.2)
```

(since `h_d = h_μ(0, c'.2)` and `h_d − 2 = h_ν(0, c'.2) − 1`,
recalling `h_ν(0, c'.2) = h_d − 1`.)

**Numerical check (S71-Σ''):**

| μ          | pμ(0,c'.2) | h_μ(0,c'.2) − 1 | LHS | pν(0,c'.2) | h_ν(0,c'.2) − 1 | RHS |
|-----------|------------|-------------------|-----|------------|-------------------|-----|
| (3,2)     | 1/2        | 2                 | 1   | 1          | 1                 | 1   |
| (3,2,1)   | 1/2        | 2                 | 1   | 1          | 1                 | 1   |
| (4,2)     | 2/3        | 3                 | 2   | 1          | 2                 | 2   |
| (3,2,2)   | 1/3        | 3                 | 1   | 1/2        | 2                 | 1   |
| (4,3)     | 1/2        | 2                 | 1   | 1          | 1                 | 1   |
| (4,3,2)   | 3/8        | 4                 | 3/2 | 1/2        | 3                 | 3/2 |
| (5,3,2)   | 8/15       | 5                 | 8/3 | 2/3        | 4                 | 8/3 |

All seven LHS = RHS ✓.  **(S71-Σ'') holds across all S62–S70 test
diagrams.**

This is the cleanest restatement found so far: (S71-Σ'') is a
pointwise identity at the single cell `(0, c'.2)` relating its
GNW probability and hook-length minus one across the two shapes.

**Why does (S71-Σ'') hold?**  From (R_μ at j=c'.2) and (R_ν at j=c'.2):

```
pμ(0, c'.2) · (h_μ(0, c'.2) − 1) = ∑_{c'.2 < k ≤ c.2} pμ(0, k)         (R_μ@c'.2)
pν(0, c'.2) · (h_ν(0, c'.2) − 1) = ∑_{c'.2 < k ≤ c.2} pν(0, k)         (R_ν@c'.2)
```

By **(S71-a)** (`pμ = pν` on c-arm row 0): the two RHS sums are
**equal**.  Therefore the two LHS are equal:

```
pμ(0, c'.2) · (h_μ(0, c'.2) − 1) = pν(0, c'.2) · (h_ν(0, c'.2) − 1)
```

**This is (S71-Σ'').**

**∎ — (S71-Σ'') follows directly from (S71-a) and the recurrence
applied at `j = c'.2`.**

Stunningly: **(S71-Σ) has a one-line proof** modulo (S71-a) (which
S71 §1 proved by strict-hook localization) and the basic GNW
recurrence.  The "Approach A" circularity arose because Approach A
operated on the WRONG sub-region (the WN row-0 cells `(0, j)` with
`j < c'.2`), where the recurrence indeed cannot close locally; the
correct reduction is to apply the recurrence at the **boundary cell**
`(0, c'.2)`, which is c'-column (not WN), and where Δp ≠ 0 but
hook-length differs.

### 5.3 The c.1 ≥ 1 generalization (caveat)

S71 §3.4 noted that for `c.1 ≥ 1`, S57.5's reduction collapses the
c'-column sum to `range (c.1 + 1)` instead of `{0}`.  The (S71-Σ'')
argument does **not** generalize verbatim — there is a subtle
walk-vanishing dependence on `c.1 = 0` that breaks at `c.1 ≥ 1`:

* **Leg walk-vanishing at `(i, c'.2)`** held in §5.1 because the
  walk from any leg cell `(r, c'.2)` with `r ≥ 1` cannot reach
  `c = (0, c.2)` — the row index is non-decreasing along the GNW
  walk.  For `c.1 ≥ 1` and `i ≤ c.1`, leg cells `(r, c'.2)` with
  `i < r ≤ c.1` are NOT walk-vanishing: the walk can step from
  `(r, c'.2)` to `(r, c'.2 + 1)` or `(r, c.2)` and continue rightward
  to `c = (c.1, c.2)` if `r ≤ c.1`.

* Thus (R_μ@(i, c'.2)) at `i ≤ c.1` for `c.1 ≥ 1` has the form

  ```
  pμ(i, c'.2) · (h_μ(i, c'.2) − 1)
        = ∑_{c'.2 < k ≤ rowEnd_μ i} pμ(i, k)  +  ∑_{i < r ≤ c'.1} pμ(r, c'.2)
  ```

  with a non-trivial leg sum (the second term is 0 only at
  `i = c.1`, where leg cells lie in rows `> c.1` and walk-vanish).

  Analogously (R_ν@(i, c'.2)) has leg sum
  `∑_{i < r ≤ c'.1 − 1} pν(r, c'.2)` (with `(c'.1, c'.2) = c'`
  removed in ν).

* The (LHS_μ − LHS_ν) = (RHS_μ − RHS_ν) equation becomes:

  ```
  pμ(i, c'.2)(h_μ(i, c'.2) − 1) − pν(i, c'.2)(h_ν(i, c'.2) − 1)
       = ∑_{c'.2 < k} [pμ(i, k) − pν(i, k)]   [zero by (S71-a)' if c-arm row i has Δp = 0]
       + ∑_{i < r ≤ c'.1 − 1} [pμ(r, c'.2) − pν(r, c'.2)]
       + pμ(c'.1, c'.2)   [the cell c' removed in ν, but pμ(c', K) = 0 since c' is a corner ≠ c]
       = − ∑_{i < r < c'.1} Δp(r, c'.2).
  ```

* So we obtain a system of `c.1 + 1` linear equations in the
  variables `{pμ(i, c'.2), pν(i, c'.2)}_{0 ≤ i ≤ c.1}` and their
  `Δp(r, c'.2)` for `i < r ≤ c.1`.  Whether this system pins down
  the c'-column F-side residual without further input is the
  **open generalization question** for c.1 ≥ 1.

  At `i = c.1`, the leg sum vanishes (all leg cells walk-vanish for
  `r > c.1`), recovering the clean (S71-Σ'') equation at row c.1:

  ```
  pμ(c.1, c'.2)(h_μ(c.1, c'.2) − 1) = pν(c.1, c'.2)(h_ν(c.1, c'.2) − 1)
  ```

  This is the only "free" equation; smaller-i equations have leg
  cross-terms.

**For c.1 = 0:** the system collapses to the single equation at
`i = 0 = c.1`, which has no leg cross-terms (the only `r` in
`0 < r ≤ c.1 = 0` is empty), and we recover (S71-Σ'') outright.

**For c.1 ≥ 1:** the cleanest path is likely a downward induction on
`i` from `c.1` to `0`, with (S71-Σ''-row-c.1) as anchor and the leg
cross-terms expressed inductively.  But this is a **larger** open
problem than (S71-Σ'') for c.1 = 0.  Detailed analysis deferred to
S73+.

**S73 test recommendation:** S71's suggested test case is
`μ = (3,2,2,1)`, `c = (2, 1)`, `c' = (3, 0)`, with `c.1 = 2`,
`c'.1 = 3`, `c.2 = 1`, `c'.2 = 0`, case 1 (`c.1 < c'.1`,
`c'.2 < c.2`).  This diagram would let us probe (S71-Σ''-row-c.1)
at `i = 2` and check the leg-cross-term equations at `i ∈ {0, 1}`
numerically.  Verifying requires computing `pμ` and `pν` at six
boundary cells across μ and ν = μ\c' = (3,2,2,0) = (3,2,2) (removing
the single-cell row at row 3).  This is left to S73 (or a companion
test session).
