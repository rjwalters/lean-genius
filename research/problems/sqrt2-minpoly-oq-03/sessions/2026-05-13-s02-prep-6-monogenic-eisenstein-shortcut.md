## §1. Mathlib bearer 1 — `Algebra.discr_mul_isIntegral_mem_adjoin`

**Location:** `Mathlib/RingTheory/Discriminant.lean:257`
(verified at v4.26.0 via `gh api repos/leanprover-community/mathlib4/contents/...?ref=v4.26.0`).

**Signature:**

```lean
theorem Algebra.discr_mul_isIntegral_mem_adjoin
    [Algebra.IsSeparable K L] [IsIntegrallyClosed R]
    [IsFractionRing R K] {B : PowerBasis K L} (hint : IsIntegral R B.gen)
    {z : L} (hz : IsIntegral R z) :
    discr K B.basis • z ∈ adjoin R ({B.gen} : Set L)
```

**Module docstring (lines 39-42, file-level comment):**

> *"Algebra.discr_mul_isIntegral_mem_adjoin : let `K` be the fraction
> field of an integrally closed domain `R` and let `L` be a finite
> separable extension of `K`. Let `B : PowerBasis K L` be such that
> `IsIntegral R B.gen`. Then for all, `z : L` we have
> `(discr K B.basis) • z ∈ adjoin R ({B.gen} : Set L)`."*

**Instantiation for `Q_sqrt2`:**

## §3. The Eisenstein verification — verbatim local template

The hypothesis `hei : (minpoly ℤ pb.gen).IsEisensteinAt (Submodule.span ℤ {(2 : ℤ)})`
needs `minpoly ℤ pb.gen = X² − C 2` plus `(X² − C 2).IsEisensteinAt
(Submodule.span ℤ {2})`.

### §3.1 `minpoly ℤ pb.gen = X² − C 2`

This is the integer-side analog of PREP-3 §1's `minpoly ℚ pb.gen = X² −
C 2`. Mathlib's
`minpoly.isIntegrallyClosed_eq_field_fractions` (or similar) lifts a
field-side minpoly to the integer-side under `IsIntegrallyClosed ℤ`.
Alternatively, define `pb_gen_isIntegral : IsIntegral ℤ pb.gen` (PREP-5
§ "Verification 5", ~5 LOC) and apply:

```lean
lemma minpoly_pb_gen_int : minpoly ℤ pb.gen = X^2 - C 2 := by
  refine minpoly.unique ℤ pb.gen ?_ ?_ ?_
  · -- monic X² - 2
    apply Monic.sub_of_left (monic_X_pow_sub_C 2 (by norm_num)) ...
  · -- aeval pb.gen (X² - 2) = 0
    rw [Polynomial.aeval_def, AdjoinRoot.eval₂_root]
  · -- minimality of degree 2
    intro p hp hp_aeval
    ...
```

### §3.2 `(X² − C 2).IsEisensteinAt (Submodule.span ℤ {(2 : ℤ)})`

**Verbatim local template:** `proofs/Proofs/AngleTrisectionCos20GalOQ01OQ03.lean:117-133`
proves `(r 3).IsEisensteinAt (Ideal.span {(3 : ℤ)})` for `r 3 := X^3 -
3·X + 3` in three steps:

```lean
theorem r_3_isEisensteinAt :
    (r 3).IsEisensteinAt (Ideal.span {(3 : ℤ)}) := by
  refine ⟨?_, ?_, ?_⟩
  · rw [show (r 3).leadingCoeff = 1 from r_3_monic, Ideal.mem_span_singleton]
    decide
  · intro k hk
    rw [r_3_natDegree] at hk
    simp only [Ideal.mem_span_singleton]
    rw [r_3_eq]
    simp only [coeff_sub, coeff_C_mul, coeff_X_pow, coeff_C, coeff_X]
    interval_cases k <;> norm_num
  · rw [Ideal.span_singleton_pow, Ideal.mem_span_singleton]
    rw [r_3_eq]
    simp only [coeff_sub, coeff_C_mul, coeff_X_pow, coeff_C, coeff_X]
    decide
```

**Adaptation to `X² − C 2` at `p = 2`:**

```lean
theorem X_sq_sub_two_isEisensteinAt :
    (X ^ 2 - C (2 : ℤ)).IsEisensteinAt (Ideal.span {(2 : ℤ)}) := by
  refine ⟨?_, ?_, ?_⟩
  · -- leadingCoeff = 1, and 1 ∉ (2)
    rw [leadingCoeff_X_pow_sub_C (show (0 : ℕ) < 2 from by norm_num),
        Ideal.mem_span_singleton]
    decide
  · -- ∀ k < 2: (X² − 2).coeff k ∈ (2)
    intro k hk
    rw [natDegree_X_pow_sub_C] at hk
    simp only [Ideal.mem_span_singleton, coeff_sub, coeff_X_pow, coeff_C]
    interval_cases k <;> norm_num
  · -- (X² − 2).coeff 0 = -2 ∉ (2)² = (4)
    rw [Ideal.span_singleton_pow, Ideal.mem_span_singleton]
    simp only [coeff_sub, coeff_X_pow, coeff_C, show ¬(0 = 2) from by norm_num,
               ite_false, zero_sub, dvd_neg]
    norm_num
```

**Note:** `Ideal.span ℤ {(p : ℤ)} = Submodule.span ℤ {(p : ℤ)}` by
definition (`Ideal R := Submodule R R`), so the `IsEisensteinAt 𝓟`
hypothesis with `𝓟 := Submodule.span ℤ {(2 : ℤ)}` is interchangeable
with `Ideal.span {(2 : ℤ)}` under `Ideal.span = Submodule.span`. The
parent file `Sqrt2Minpoly.lean:44-69` uses `Ideal.span {(2 : ℤ)}` for
`irreducible_of_eisenstein_criterion`; same conventions apply here.

**Sanity check (numerical):**
- `leadingCoeff (X² − 2) = 1`. `1 ∉ (2)` since `1 ≠ 2 · k` for `k : ℤ`. ✓
- Coeff at degree 1: `0`. `0 ∈ (2)` (trivially `0 = 2·0`). ✓
- Coeff at degree 0: `−2`. `−2 ∈ (2)` (`−2 = 2·(−1)`). ✓
- Coeff at degree 0: `−2 ∉ (2)² = (4)` (`−2 ≠ 4·k` for any `k : ℤ`). ✓

The `decide` and `norm_num` tactics handle all four checks.

**LOC:** ~12 lines (3 sub-proofs at 3-4 lines each).

## §4. The complete bridge — putting it together

```lean
/-- The integer-basis bridge: 𝓞 Q_sqrt2 ⊆ adjoin ℤ {pb.gen}.
    Strategy: (1) discr-route bound 8 • z ∈ adjoin (Mathlib),
              (2) Eisenstein at 2, n = 3 (Mathlib).
    Bypasses half-integer case analysis. -/
theorem ringOfIntegers_subset_adjoin :
    ∀ z : Q_sqrt2, IsIntegral ℤ z → z ∈ Algebra.adjoin ℤ ({pb.gen} : Set Q_sqrt2) := by
  intro z hz
  -- §1: Mathlib gives 8 • z ∈ adjoin ℤ {pb.gen}, since discr = 8
  have h_discr : Algebra.discr ℚ pb.basis = (8 : ℚ) := rational_discr  -- PREP-3/4
  have h_smul : (8 : ℚ) • z ∈ Algebra.adjoin ℤ ({pb.gen} : Set Q_sqrt2) := by
    rw [← h_discr]
    exact Algebra.discr_mul_isIntegral_mem_adjoin pb_gen_isIntegral hz
  -- Recast as (2 : ℤ)^3 • z ∈ adjoin ℤ {pb.gen}
  have h_smul_int : ((2 : ℤ) ^ 3 : ℤ) • z ∈ Algebra.adjoin ℤ ({pb.gen} : Set Q_sqrt2) := by
    convert h_smul using 1
    push_cast; ring
  -- §3: Eisenstein at 2 + minpoly identification
  have h_minpoly : minpoly ℤ pb.gen = X^2 - C 2 := minpoly_pb_gen_int
  have h_eisen : (minpoly ℤ pb.gen).IsEisensteinAt (Ideal.span {(2 : ℤ)}) := by
    rw [h_minpoly]; exact X_sq_sub_two_isEisensteinAt
  -- §2: Mathlib chain to z ∈ adjoin
  exact mem_adjoin_of_smul_prime_pow_smul_of_minpoly_isEisensteinAt
    Int.prime_two pb_gen_isIntegral hz h_smul_int h_eisen
```

**Estimated LOC:** ~15 lines for the headline theorem above, plus ~30
LOC of supporting lemmas (§3 total) = ~45 LOC. **Zero sorries**.

## §6. Generalizability to other quadratic fields

PREP-5 § Honesty noted:

> *"The '𝓞 K = ℤ[pb.gen]' claim relies on `d = 2 ≡ 2 mod 4`. For `d =
> 5 ≡ 1 mod 4`, `𝓞 K = ℤ[(1+√5)/2]` ≠ `ℤ[pb.gen]`, so this PREP's
> bridge would not transfer verbatim to a hypothetical `sqrt5-oq-*`
> sibling without an adjustment."*

The Mathlib-citation route in PREP-6 makes this generalizability
explicit:

| `d` | `d mod 4` | `discr(X² − d)` | Eisenstein at? | Index `[𝓞 K : ℤ[√d]]` | PREP-6 transfers? |
|---:|---:|---:|---|---:|---|
| 2 | 2 | 8 = 2³ | yes (at 2) | 1 | ✓ |
| 3 | 3 | 12 = 2²·3 | yes (at 3) | 1 | ✓ |
| 5 | 1 | 20 = 2²·5 | NO | 2 | ✗ (must use `(1+√5)/2`) |
| 6 | 2 | 24 = 2³·3 | yes (at 2 OR 3) | 1 | ✓ |
| 7 | 3 | 28 = 2²·7 | yes (at 7) | 1 | ✓ |
| 10 | 2 | 40 = 2³·5 | yes (at 2 or 5) | 1 | ✓ |
| 11 | 3 | 44 = 2²·11 | yes (at 11) | 1 | ✓ |

**Coverage:** PREP-6 transfers verbatim to ALL square-free `d` with `d
≡ 2, 3 (mod 4)` because:

- **`d ≡ 2 (mod 4)` ⇒ `d = 2k` with `k` odd squarefree:** discr is
  `4d = 8k`, divisible by `2³`; X² − d is Eisenstein at 2.
- **`d ≡ 3 (mod 4)` ⇒ `d` odd squarefree:** discr is `4d`. Eisenstein
  at any odd prime factor `q ∣ d` (since `q² ∤ d` by squarefree, and
  `discr = 4d` is divisible by `q²` only if `q² ∣ 4d`, true exactly
  when `q = 2` which is excluded for `d` odd OR `q² ∣ d`, excluded by
  squarefree). Then PREP-6 chain works at `(p, n) = (q, 2)`.

**Coverage gap:** PREP-6 does NOT transfer to `d ≡ 1 (mod 4)` because
`X² − d` is not Eisenstein at any prime (`disc = 4d`, but `4 = 2²` and
`d` odd ⇒ both 2 and any `q ∣ d` have `4d / q²` not divisible by
`q⁻¹`). For `d ≡ 1 (mod 4)`, `𝓞 K = ℤ[(1+√d)/2]` and a different
PowerBasis is required. Outside the `sqrt2-minpoly` slug scope, but
flagged as a **PREP-6-specific scope limit**.

**Implication for future seeker / hermit:** the
`IsRealQuadraticExtension` upstream Mathlib contribution proposed in
PREP-5 § Verification 4 should branch on `d mod 4` and provide separate
shortcut lemmas for the `d ≡ 2, 3 (mod 4)` case (PREP-6 chain) vs the
`d ≡ 1 (mod 4)` case (`(1+√d)/2`-PowerBasis chain). This is a 2-PR
upstream contribution, not 1.

## §8. Honesty / what could be wrong

- **`Algebra.IsSeparable ℚ Q_sqrt2`** is stated as "follows from
  `CharZero`". Verified: `Mathlib.FieldTheory.Separable` provides
  `Algebra.IsSeparable.of_finite_of_isAlgClosure_or_charZero` (paraphrased
  name) — the exact instance discovery may need an `inferInstance` or a
  small `Algebra.IsSeparable` annotation. **Risk: low.**
- **The ℤ-version of `minpoly_pb_gen_int`** is sketched but not fully
  written. The `minpoly.unique` direct path is ~15 LOC; the
  `IsIntegrallyClosed`-transfer path may be a one-liner via
  `minpoly_isIntegrallyClosed_eq_field_fractions`. **Risk:** the exact
  Mathlib API name was not verified at v4.26.0 (search/code rate-limit
  exhausted at 30/hr); fallback is the direct `minpoly.unique` path.
- **`Int.prime_two`** is the standard name, but in v4.26.0 it may be
  spelled `Nat.prime_two` (cast via `Nat.Prime.prime_int`) or
  `Int.prime_iff_natAbs_prime.mpr (...)`. The parent file
  `Sqrt2Minpoly.lean:48` uses `Int.prime_iff_natAbs_prime.mpr (by
  native_decide)` which works. **Risk: low** (just a name refactor).
- **The `(8 : ℚ) • z = (2 : ℤ)^3 • z` coercion** is `push_cast; ring`
  but may need an explicit `IsScalarTower ℤ ℚ Q_sqrt2` invocation.
  **Risk: low** (Mathlib has `IsScalarTower` instances for all
  number-field setups).
- **PREP-6's §6 generalizability table** asserts coverage for `d ≡ 2,
  3 (mod 4)` but the `d ≡ 2 (mod 4)` case requires `d/2` squarefree (so
  `d ∈ {2, 6, 10, 14, ...}` minus `d = 2k` with `k = q²m`). For `d =
  8, 12, 18, ...` (non-squarefree), `Q(√d) = Q(√(d / k²))` so the slug
  reduces to a smaller squarefree `d`. **Risk: vacuous** (the
  `nth-root-irrational` parent's irreducibility hypothesis on `X² − d`
  already implies `d` is non-square, which doesn't quite imply
  squarefree, but for this `sqrt2-minpoly-oq-03` slug `d = 2` is
  squarefree by inspection).
- **`Nat.gcd(p, discr) = 1`** is implicit in §6 — the Eisenstein
  hypothesis at `p` requires `p ∣ discr`, so the bridge transfers
  exactly when there's a single prime where Eisenstein applies. For
