### Headline finding

**Both** parity-of-`n/2` sub-cases admit a clean coprime decomposition
of `3 · C(n, 3)`. Kummer is **not** needed for m=3.

S8's state.md (Blockers section, prior version) said for `n ≡ 2 mod 4`:
> Both `n` and `n-2` ≡ 2 mod 4, so `(n-2)/2` is odd, but `n/2` is also
> odd — net `v_2 = 1` on each, total `v_2(...)` = 2. Need to verify
> `lcmRange n` has at least `v_2 = 2 + ...`. Probably Kummer.

This is **false**. The factorization `3·C(n,3) = (n/2)(n-1)(n-2)` is
not the only one available. By re-grouping the lone `/2` differently
(absorbing it into `n-2 = 2(m-1)` rather than into `n/2`), the
factorization `3·C(2m, 3) = m·(2m-1)·(2m-2)` for `m` odd has all three
factors pairwise coprime. No Kummer required.

### Setup

Parametrize `n = 2 * m` (`m ≥ 2`, so `n ≥ 4`). Combining Part 7
`two_mul_three_mul_choose_three_eq` (`2 · 3 · C(n, 3) = n(n-1)(n-2)`)
with `n - 2 = 2(m - 1)` and cancelling the leading `2` gives the
**uniform identity**:

```
(*)   3 · C(2m, 3) = (2m) · (2m - 1) · (m - 1)        for m ≥ 2
```

By re-grouping `(2m) · (m - 1) = m · 2(m - 1) = m · (2m - 2)`:

```
(**)  3 · C(2m, 3) = m · (2m - 1) · (2m - 2)          for m ≥ 2
```

Both identities are exact ℕ statements (no division involved on the
RHS), and they equal the same value of `3 · C(2m, 3)`.

### Sub-case A.1: m even (n ≡ 0 mod 4)

Use **(*)**: `3 · C(2m, 3) = (2m) · (2m - 1) · (m - 1)`.

Pairwise-coprime check:
- `gcd(2m, 2m - 1) = 1` (consecutive integers).
- `gcd(2m, m - 1)`: any common prime `p` divides `2m - 2(m-1) = 2`, so
  `p ∈ {1, 2}`. For `m` even, `m - 1` is odd, so `p ≠ 2`. Hence `p = 1`.
- `gcd(2m - 1, m - 1)`: from `(2m - 1) - 2(m - 1) = 1`, any common
  divisor must divide `1`. Hence `= 1`.

Each factor is in `[1, n]` for `m ≥ 2`:
- `2m = n`: `dvd_lcmRange (le_refl n)`.
- `2m - 1 = n - 1`: `dvd_lcmRange (Nat.sub_le n 1)` after positivity.
- `m - 1 ≥ 1`: `m - 1 ≤ m ≤ 2m = n`.

By two applications of `Nat.Coprime.mul_dvd_of_dvd_of_dvd` (mirroring
S8's `mul_choose_dvd_lcmRange_three_odd` template),
`(2m)(2m-1)(m-1) ∣ lcmRange n`, hence `3 · C(n, 3) ∣ lcmRange n`. ☐

### Sub-case A.2: m odd (n ≡ 2 mod 4)

Use **(**)**: `3 · C(2m, 3) = m · (2m - 1) · (2m - 2)`.

Pairwise-coprime check:
- `gcd(m, 2m - 1)`: `2m - 1 ≡ -1 (mod m)`, so any common divisor
  divides `1`. Hence `= 1`.
- `gcd(m, 2m - 2)`: `2m - 2 ≡ -2 (mod m)`, so any common divisor
  divides `2`. For `m` odd, no common factor of 2. Hence `= 1`.
- `gcd(2m - 1, 2m - 2) = 1` (consecutive integers).

Each factor is in `[1, n]` for `m ≥ 2`:
- `m ≤ 2m = n`.
- `2m - 1 = n - 1`.
- `2m - 2 = n - 2 ≥ 2 ≥ 1`.

Same coprime-mul-dvd assembly. ☐

### Why the S8 reasoning broke

S8 considered the factorization `3·C(n,3) = (n/2)(n-1)(n-2)` (i.e.,
**(*)** with `m` replaced by `n/2`, no re-grouping). For `n ≡ 2 mod 4`,
`n/2 = m` is odd and `n - 2 = 2(m-1)` is even with `(m-1)` even — so
`gcd(n/2, n-2)` could be `≥ 2`. Specifically:

```
gcd((n/2), (n-2)) = gcd(m, 2(m-1)) = gcd(m, 2(m-1))
```

For `m` odd: `gcd(m, 2) = 1` and `gcd(m, m-1) = 1`, so
`gcd(m, 2(m-1)) = 1`. Wait — this also yields coprime!

So **even (*)** would have closed `n ≡ 2 mod 4`, had S8 noticed that
`gcd(m, 2(m-1)) = 1` for `m` odd. The "v_2 = 2 on each side"
observation was correct in identifying that the `2`-adic valuations
sum to 2, but **only one factor `(2(m-1))` can absorb both 2's**;
the `m` factor is pristine.

The (**) re-grouping makes this clearer by collapsing `2(m-1)` into a
single ℕ literal `2m - 2`, and the `gcd(m, 2m-2) = 1` is then a
direct one-step coprime check.

### Lean tactical concerns and mitigations

1. **`(2m - 2) = 2 * (m - 1)`**: needed in identity (*)'s proof.
   `omega` handles this for `m ≥ 1` (truncated subtraction is fine
   since `2m - 2 ≥ 0`).

2. **Helper `three_mul_choose_three_eq_of_double`**: uses the cancel
   `Nat.eq_of_mul_eq_mul_left (by decide : (0 : ℕ) < 2)` pattern.
   The Lean tactic chain is short and analogous to S6
   `mul_choose_dvd_lcmRange_two`'s `show` + `rw [Nat.choose_one_right]`.

3. **Coprime `gcd(2m, m-1) = 1` for `m` even**: cleanest tactic is
   `obtain ⟨j, rfl⟩ := h_m_even` to expose `m = 2j`, reducing to
   `Coprime (4j) (2j - 1)`. Then `4j = 2(2j-1) + 2`, which gives
   `Coprime (2(2j-1) + 2) (2j-1)`. Use
   `Nat.coprime_add_self_left.mpr (Nat.coprime_self_add_right.mpr
   (Nat.coprime_one_right _)).symm` style — verify the exact lemma
   name in the m=2 sub-step.

4. **Coprime `gcd(m, 2m - 2) = 1` for `m` odd**: factor as
   `2m - 2 = 2 * (m - 1)`. Use
   `Nat.Coprime.mul_right` after showing
   `gcd(m, 2) = 1` (m odd) and `gcd(m, m-1) = 1` (consecutive). The
   second is the standard `Nat.coprime_self_add_right` rewrite from
   S8.
