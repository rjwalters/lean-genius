### Definitions (2)

```lean
def topCellsOfDim (K : Finset (Finset E)) (d : Nat) : Finset (Finset E) :=
  K.filter (fun s => s.card = d + 1)

def MixedPseudomanifold (K : Finset (Finset E)) : Prop :=
  ∀ d : Nat, ∀ f : Finset E, f.card = d →
    ((topCellsOfDim K d).filter (fun s => f ⊆ s)).card ≤ 2
```

### Theorems (3)

1. `topCellsOfDim_eq_of_pure`: when every cell in `K` has cardinality `d + 1`, the stratum at `d` equals `K`. **Proof**: `Finset.filter_eq_self.mpr`.

2. `topCellsOfDim_eq_empty_of_pure`: when every cell in `K` has cardinality `d + 1`, strata at other dimensions are empty. **Proof**: `Finset.filter_eq_empty_iff` + `omega` on `s.card = d + 1` vs `s.card = d' + 1` with `d' ≠ d`.

3. `MixedPseudomanifold.of_pure`: a pure pseudomanifold lifts to a mixed pseudomanifold. **Proof**: case-split on `d' = d`. In the equal case, rewrite via `topCellsOfDim_eq_of_pure` and apply `hpseudo`. In the unequal case, rewrite via `topCellsOfDim_eq_empty_of_pure`, then `Finset.filter_empty` + `Nat.zero_le _`.
