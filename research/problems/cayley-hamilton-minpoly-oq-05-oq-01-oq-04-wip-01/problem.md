# Problem: Complete Nonderogatory to Cyclic Vector — The General Case (All Fields)

## Statement

### Plain Language

The nonderogatory cyclic vector theorem states: if M ∈ Mₙ(K) has minpoly = charpoly (nonderogatory),
then M has a cyclic vector v such that {v, Mv, M²v, …, Mⁿ⁻¹v} is a basis.

The previous work proved this for infinite fields (via union avoidance) and established a clean
characterization `cyclic_iff_ann_eq_minpoly`. The key `sorry` in `CayleyHamiltonMinpolyOQ05OQ01OQ04.lean`
(theorem `nonderogatory_has_cyclic_vector_any_field`) is:

> **Prove `nonderogatory_has_cyclic_vector_any_field` over any field K, without the full
> structure theorem for f.g. modules over a PID (which is not in Mathlib).**

The blocking proof step is the PID module structure theorem (cyclic decomposition):
  V ≅ K[X]/(d₁) ⊕ … ⊕ K[X]/(dᵣ), d₁|…|dᵣ

With minpoly = charpoly (nonderogatory), we need r = 1, giving V ≅ K[X]/(minpoly) — cyclic.

### Formal Statement

```lean
theorem nonderogatory_has_cyclic_vector_any_field
    {K : Type*} [Field K] {n : ℕ}
    (M : Matrix (Fin n) (Fin n) K) (h : IsNonderogatory M) :
    ∃ v, IsCyclicVector M v
```

where:
```lean
def IsCyclicVector (M : Matrix (Fin n) (Fin n) K) (v : Fin n → K) : Prop :=
  LinearIndependent K (fun i : Fin n => (M ^ (i : ℕ)).mulVec v)

def IsNonderogatory (M : Matrix (Fin n) (Fin n) K) : Prop :=
  minpoly K M = Matrix.charpoly M
```

## The Key Blocker

The standard proof route is:
1. Treat Kⁿ as K[X]-module via M (action: p · v = (aeval M p).mulVec v)
2. Apply cyclic decomposition theorem: V ≅ K[X]/(d₁) ⊕ … ⊕ K[X]/(dᵣ)
3. Nonderogatory forces r = 1 → V is cyclic

**Blocker**: Step 2 requires `Module.InvariantFactors` or equivalent PID structure theorem,
which is ~500+ lines of deep algebra not in Mathlib 4.26.

## Alternative Approaches to Explore

### Approach A: Induction on degree of minpoly
- Base: deg=1 → M = λI → any nonzero v works
- Step: Split via primary decomposition (is primary decomp in Mathlib?)
- If minpoly = p₁^e₁ · … · pₖ^eₖ and nonderogatory, then dim(ker p₁^e₁(M)) = e₁·deg(p₁), etc.

### Approach B: Direct rank argument
- Show: the map φ: K[X] → Kⁿ, f ↦ f(M)·v0 is surjective for some v0 iff minpoly = charpoly
- This might be accessible via `LinearMap.span_singleton_eq_top` or similar
- Key insight: nonderogatory iff the cyclic K[X]-submodule generated by some vector equals Kⁿ

### Approach C: Companion matrix reduction
- nonderogatory M is similar to its companion matrix C(charpoly)
- The companion matrix has an obvious cyclic vector: e₁
- Transfer via similarity: `cyclic_vector_of_similar` (already proved!)
- **Issue**: Need M similar to companion matrix. This follows from rational canonical form.
- In Mathlib: does `Matrix.isConj_companion` or `Matrix.IsSimilar.companion` exist?

### Approach D: Existential witness via eval map
- Consider the evaluation map: for each v ∈ Kⁿ, the annihilator ann(v) ⊆ K[X] is the ideal of p with p(M)v=0
- `cyclic_iff_ann_eq_minpoly` (already proved!) gives: v cyclic ↔ ann(v) = (minpoly)
- Need to show: there exists v with ann(v) = (minpoly) when minpoly = charpoly
- This is equivalent to: Kⁿ is a cyclic K[X]-module
- Can this be shown from dimension counting alone?
