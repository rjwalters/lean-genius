# fundamental-theorem-calculus-oq-01

## Problem Description

Formalize FTC for the Lebesgue integral: if $F$ is absolutely continuous on $[a,b]$, then $F'$ exists a.e., is Lebesgue integrable, and $\int_a^b F' = F(b) - F(a)$ — the Lebesgue-Vitali theorem that extends FTC beyond continuous integrands
