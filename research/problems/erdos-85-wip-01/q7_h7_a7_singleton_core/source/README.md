# Conditional H7 a7 singleton-core cover

Assume the pending arbitrary-high conclusion s_i >= 3, where s_i counts empty incidences at the two singleton neighbours of high i. At a7, sum_i s_i=21, so each s_i=3. By accepted singleton positivity2085, each high then has exactly one singleton with one empty neighbour (singleton degree3) and one with two (singleton degree1).

The singleton induced graph consequently has seven vertices of degree3 and seven of degree1. Let J be its induced graph on the degree3 vertices. It is C4-free with maximum degree3. If k pairs of degree1 vertices form isolated edges, the other 7-2k leaves attach to the core. Thus 21-2|E(J)|=7-2k, or |E(J)|=7+k, where 0<=k<=3. For each core vertex v the number of attached leaves is exactly3-degree_J(v); the core uniquely determines the unlabelled singleton graph.
