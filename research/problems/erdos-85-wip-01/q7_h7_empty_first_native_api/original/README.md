# Native port of accepted empty-first row/AC API2101

filter.cpp ports the validated high+empty-complete graph checker, least-uncovered-colour row enumeration and reciprocal/full-neighbour arc consistency from reference.py, which is a byte-exact copy of accepted2101. native.py exposes the same check call through ctypes. build.sh compiles the small library. The supported public node cap is an integer0..2147483647; research limits remain100000. No new incidence-family work has used this implementation.

Traversal equivalence: infer and sort the same35active vertices, consider candidates in ascending vertex order, use the same least uncovered high colour, and apply the same support/immutable-neighbour tests and degree bounds. Every recursive call and every compatibility comparison consumes one shared tick. All35domains complete before checking empty rows. Arc pairs, rows and supports retain the reference ordering. Removals are committed only after a whole pairwise batch finishes. The copied original domains remain immutable in the output. UNKNOWN generation omits the unfinished domain; UNKNOWN arc preserves previous batches and discards pending removals.

The complete JSON objects preserve statuses, stages, vertex/empty-vertex fields, ordered row domains/deletion events, remaining domains and node counts exactly. The wrapper normalizes JSON integer keys as the Python API does. Invalid graph/budget cases raise; native failures are never interpreted as exclusions. The clock uses the earlier reviewed2086macOS mach_absolute_time/CLOCK_MONOTONIC bridge, with an epoch-agreement check against Python time.monotonic on import. Deadlines are shared absolute timestamps, and wall-clock stopping points may differ while always yielding UNKNOWN.

The node counter is int64_t, avoiding the INT_MAX issue caught in the earlier host API review. counter_boundary.cpp starts it at2147483647 and checks that the next tick reaches2147483648 and raises Limit. The executable passes with undefined-behaviour sanitizer and no recovery; no graph search occurs in this unit.

Equivalence checks use20already checked fixed partials (two originalAPI fixtures and18completed pilot bases), not new research domains. There are178full-object comparisons at zero/small budgets, exact row-generation boundaries, before/at terminal node counts and100000, plus20expired-deadline comparisons. Invalid selfloop, negative budget and noninteger budget cases are rejected by both APIs. Full-budget aggregate timings on this sample were0.0566seconds Python and0.00733native; this does not guarantee a speedup for every input.

Independent algorithm/FFI/clock review is requested before research use. Tests and binaries are retained with source hashes and the accepted reference review. Fixture equality supports the code audit but does not replace the completeness proof. No old capped research case was retried; no new incidence family, H7case, Lean theorem or Erdős85result is excluded here.
