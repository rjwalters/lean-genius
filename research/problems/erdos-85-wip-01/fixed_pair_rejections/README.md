All 214 Lean modules compiled successfully in staged ordinary-kernel builds.
The 850 printed exports use only standard axioms or subsets. Source hashes,
terminal receipts, and logs are retained under `evidence/`; `FINAL_AUDIT.json`
records the complete audit. The portable checker has not been rerun as one batch.

The combined theorem rejects the 1120 explicitly represented cross completions
for full U compact parameters(6,6,15) and R representative14. Seventy separate
representative rejections are combined with sixteen checked root/block-preserving
permutations. Every orbit module links literal adjacency to the original full
block graph. The checked 140-leaf table links the proposed ordered coverage leaves to these rejections.

A separate kernel coverage theorem
must show that every admissible actual joint witness reaches one of these listed
completions. This package alone does not exclude the entire pair or solve Erdős85.

From the integration proofs directory, after building the imported repository
proof modules, run `lake env python3 PACKAGE/check.py --workers 2`.
An optional `--build-dir PATH` retains all compiled outputs in a chosen separate
empty directory. Source hashes are verified before compilation. The checker builds
shared modules, individual certificates and orbits, assembly links, and the final
theorems in dependency order. Every source check must exit0 and its printed
exports must use only the three standard axioms or subsets. No native_decide
or external computation is used as a proof axiom.

`assembly-manifest.json` and `coverage-leaf-map.json` record Python linkage data;
they are not coverage proofs. The Lean equalities and imported theorem statements
provide the proof links. Generated oleans are local build products, not distributed
proof certificates.
