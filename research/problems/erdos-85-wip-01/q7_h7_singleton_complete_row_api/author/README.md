# Necessary residual-row filter preserving singleton edges

This adapts accepted review 2101 to a7 partial graphs with all high, empty, and singleton-to-singleton edges assigned. The validator accepts the standard 49-vertex high/support multiplicities, high degree eight, empty degree seven, exact high-empty saturation, and C4-freeness. Pair vertices have no assigned nonempty-low neighbors. Each high has one single-empty and one double-empty singleton, with induced singleton degrees three and one respectively; same-high singleton edges are forbidden by accepted 2096. These are input preconditions, not new exclusions.

Only singleton-pair and pair-pair edges remain. Each singleton needs two or three pair neighbors, and each pair vertex needs four or five nonempty-low neighbors. High saturation requires the supports of all low neighbors to partition the seven high colours. Known singleton neighbors have already supplied some colours; their supports are removed from the row target. Remaining candidate supports partition exactly the unused colours, with the required residual degree. A singleton may only select pair vertices. A pair may select singleton or pair vertices. Assigned edges and self loops are never candidates.

The least-uncovered-colour recursion of 2101 still enumerates each row once: in a disjoint exact cover there is a unique selected vertex containing that colour. Candidate versus existing-neighbor and candidate versus selected-neighbor common-neighbor checks exactly prohibit C4s in the added star. Every added edge touches its center, so any new C4 contains that center. The retained singleton edges participate in these checks.

All 35 domains must finish before an empty domain is used to reject. The arc-consistency code is byte-for-byte inherited from the accepted reference: edge reciprocity and at most one common final neighbor are necessary for each pair of final rows. Deletion batches are applied only after their support search finishes. Interrupted generation or arc work returns UNKNOWN and never supplies an exclusion. Original default limits remain 100000 operations with a caller-supplied shared monotonic deadline. No capped research tree is retried.

The test inputs are exactly the 33 S-complete graphs from the already reviewed fixed-colouring pilot 2103. No new incidence family was searched. An independent explicit support-partition template construction regenerates 1155 complete domains and all 2896 rows. Every fixture is row-infeasible. Zero-budget, expired-deadline and invalid self-loop tests cover every fixture; an interrupted synthetic arc batch retains its original domains. Runtime was 1.25 seconds. Arc logic is unchanged from reference.py, whose bytes are pinned to 2101; these particular research fixtures do not exercise arc deletions.

This is a necessary filtering API and fixed-fixture validation, not a full graph search, F-class exclusion, H7 closure or Lean theorem. It remains pending independent review before new-family use.
