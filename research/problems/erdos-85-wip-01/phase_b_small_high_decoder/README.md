# H3/H5/H7 SAT-candidate graph check

`verify_small_high_sat_graph.verify_candidate(cnf, model, high_count, profile, expected_cnf_sha256)` returns `GRAPH_WITNESS_VERIFIED` only after complete model/CNF verification, exact input hash/variable-count agreement, and independent graph checks. Supported inputs are the two H3 canonical bases, corrected H5 t0/t1/t2 roots, and compact H7/T0 roots. The model log is bounded at4MiB and variable IDs are bounded before the generic assignment reader allocates its array.

The decoder reads low/low edge variables, adds the fixed high/support incidences, and checks all49 degrees (8 for the selected high vertices,7 otherwise), simplicity, high independence, and all1176 endpoint-pair common-neighbor counts. A graph passing those direct checks is a genuine49-vertex C4-free graph with the stated degree profile, independently of the CNF interpretation. Encoding/mapping checks guard against losing a valid candidate through a decoding error. A failure remains a SAT candidate/error requiring investigation; it never becomes UNSAT. A decoded graph rejected after complete model/CNF verification is retained in `GraphDecodeError.evidence` with edge list, statistics and CNF/model hashes. The CLI writes that diagnostic JSON and exits nonzero. Preserve the original CNF and model on failure.

H3 Python bases and H5 Lean freight differ in high-edge variable ordering. Their low/low suffixes agree with the decoder: H3 starts142 and H5 starts231. H7 uses1..861 for all low/low edges. `FIRST_AUDIT_FAILURE.md` retains the discovery of the initial high-edge-order mistake before publication.

The retained-input audit checks every fixed high unit plus51888 C4 clauses binding all1176 edge IDs for each of the five H3/H5 bases. It also independently reconstructs all687260 C4 clauses of the compact H7 base, binding all861 low-edge IDs and its fixed incidences, and checks every21-unit empty-cube list for all43 H7 classes. Every actual base hash is checked before the clause comparison. Degree-counter correctness is not inferred from this prefix audit: the decoded graph degrees are checked directly.

Run `python3 -B -m unittest test_verify_small_high_sat_graph.py -v` in `sat49`. Run `python3 -B phase_b_small_high_decoder/audit_retained_edge_numbering.py` from the problem directory to replay the read-only retained-input audit. The audit expects the retained local base paths recorded in the sector inventories. No CNF is generated and no solver is invoked.

Eight tests cover genuine small C4-free positive controls, an actual4-cycle, edge-map bijections, every support census, invalid profiles/missing assignments, oversized model indices, a completely satisfied synthetic CNF whose decoded graph fails the degree requirement, and nonzero CLI rejection with retained graph diagnostics. No positive order49 SAT model is available, so no end-to-end witness or profile exclusion is claimed. Source and evidence hashes are recorded in `RECEIPT.json`.

H5 accepts the corrected29,632-variable encoding. A legacy29,500-variable H5 file is refused; this is intentional. The high/support incidences are constructed from the selected canonical template, not independently re-checked by comparing the constructed graph to that same template. The retained fixed-unit audits bind these templates to the actual inputs.
