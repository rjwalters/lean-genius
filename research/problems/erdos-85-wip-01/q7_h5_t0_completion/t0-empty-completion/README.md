# Provisional T0 alternative-singleton / empty-layer reduction

Of the fourteen T0 singleton-layer survivor cores, thirteen exhaust under necessary empty-layer constraints. Core 5774048758818 reaches the 100,000-node cap (100,001st tick) and remains UNKNOWN. All fourteen were visited; total run 9.12 seconds. This is a provisional author result pending independent review, not a sector exclusion or a Phase B queue change.

Every hosting and every singleton completion of each selected core remains in the search. At each completed singleton layer, empty_capacity.feasible enumerates all nonempty neighborhoods of an empty vertex: support masks partition five colours, all guest vertices have positive residual degree, and no guest pair already has a common neighbor. It then seeks fourteen distinct such rows realizing every nonempty residual degree while prohibiting a guest pair from appearing twice. Identical rows cannot repeat, since any support partition has at least two guests. At a completed incidence cover it requires every empty vertex to have at least as many individually legal empty partners as its residual degree. This is necessary and deliberately weaker than simultaneous empty-edge completion.

The helper comes from the T1 review-2032 source, with nonempty range changed to 5..34, empty range to 35..48 and empty count to fourteen. Its source semantics have been audited, but the T1 independent review is still pending. The caller uses the frozen reviewed T2/T0 reciprocal-edge DFS, replacing its first-singleton-witness return with the helper check. A failed helper check causes backtracking through alternative singleton completions. Helper nodes and singleton nodes share the same 100,000 per-core bound, with a 60-second wall bound; TimeoutError propagates to CAPPED, never to an exclusion. The capped core was not retried.

Earlier T0 singleton census evidence remains frozen in ../t0-singleton-pilot and ../t0-singleton-tail (reviews 2031/2033). Together those runs leave exactly the fourteen cores selected here. Input/output source pins are in PINS.json. Run completion.py from this directory; it writes empty-t0.json. Computational necessary-condition evidence only; no Lean theorem or complete Erdős 85 solution is claimed.
