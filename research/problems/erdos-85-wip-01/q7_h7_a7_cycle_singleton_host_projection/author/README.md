# A7 cycle-empty graph: complete singleton projection

Assume accepted 2085, 2091 and 2097, and fix the empty graph F=C7. Each empty vertex has two empty neighbours, two pair neighbours and three singleton neighbours. There are seven double-empty singleton vertices of induced singleton degree one, and seven single-empty singleton vertices of induced singleton degree three.

Encode the seven double-empty singleton host pairs by a simple graph X on the seven empty vertices. The pairs are distinct and have no common neighbour in F by the exact partial incidence criterion. Thus X has seven edges among the fourteen pairs at cycle distance one or three. Its degree is at most three. Empty x then hosts exactly 3-deg_X(x) single-empty singleton vertices. These counts sum to seven. Naming the double-empty vertices by their X edges and naming the single-empty vertices by host and local index loses no extension: permutations of otherwise identical singleton names extend to the rest of the graph.

The raw X domain was previously observed in the positive-singleton-host capacity census; this package repeats its small finite count for provenance, and adds the dihedral quotient and complete singleton-edge extension. cover.py examines all 3432 seven-subsets, retains 2606 X graphs, and computes disjoint Aut(C7) orbits: 202 representatives (172 size 14, 28 size 7, two size one). Every reconstructed 21-vertex E/S graph is directly checked C4-free.

rows.py enumerates every possible singleton row of target degree one or three. Adding a star can create a C4 only through its center: two final neighbors must have a common neighbor other than that center. This exact test yields 19671 rows across 202 complete domains, without any empty domain. complete.py enforces edge reciprocity and at most one common final neighbor for every singleton pair, with arc consistency and exhaustive MRV branching. Row validity already handles E/E and E/S pairs; pairwise final-row compatibility handles S/S pairs. Hence the resulting assignments are exactly all C4-free singleton graph extensions of the projection. No high or pair vertices are assigned.

The completion pass finishes all 202 cases: 151 have no singleton extension, and 51 have 459 labelled singleton extensions in total. The maximum per-case operation count is 99768 under the fixed 100000 limit; overall time is 0.795 seconds under 60 seconds. There are no UNKNOWN or unvisited cases, and no capped case was retried. Singleton names remain labelled within each X representative, so 459 is a complete covering list, not an isomorphism count.

verify.py independently reconstructs every possible star and checks C4 by counting length-two paths. It regenerates all 19671 rows. A separate direct graph search processes vertices in fixed order, chooses edges only to future vertices with remaining capacity, and tests the entire graph after every star. It reproduces all 459 edge sets exactly, all 202 cases complete, in 28.71 seconds with the same 100000 per-case and 60-second guards.

This yields a smaller necessary projection for the F=C7 part of a7: only 51 X classes remain, represented by 459 E/S graphs. It does not exclude F=C7, other empty graphs, a7, H7 or Erdős 85. High colours and all pair vertices/edges remain to be assigned. There is no Lean theorem or solver queue change. Independent review is requested before downstream use.
