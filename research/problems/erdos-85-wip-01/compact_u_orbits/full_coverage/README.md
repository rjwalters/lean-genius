# Complete full-U compact orbit coverage

`FullURestrictedAssembly.covered` is kernel-checked: every C4-free full-template compact parameter is exactly a relabeling of one of55 listed representatives, by the public diagonal-permutation/optional-row-swap equivalence. Arbitrary Lean parameters are covered by the public exhaustive code surjectivity theorems. The structural shared-edge theorem first restricts225 mask pairs to100; the100 retained shards each check all120 permutations with explicit C4-or-orbit certificates.

All100 shard compiles terminated rc0 in388.62s total with two local Lean processes. The combined assembly terminated rc0 in6.44s. A separate38.50s check proves all55 representatives C4-free and their compact parameter encoding injective. All204 printed theorem exports use only propext, Classical.choice and Quot.sound. Every shard was subsequently regenerated byte-identically. Source/log/run hashes and exact pair coverage were audited independently of the runner's complete flag.

These55 are distinct compact parameter entries; no claim that they are55 nonisomorphic graphs is made. The theorem covers the normalized full template only. Deficient coverage, actual-graph/terminal transport and sufficient representative exclusions for H3 remain separate obligations. Erdős85 is not solved by this package.

Reproduction: from the parent directory run `python3 generate.py` to create witnesses.json. From the integration worktree proofs directory run `lake env python3 ABSOLUTE_PACKAGE_PATH/run.py --output NEW_EMPTY_DIRECTORY --witnesses ABSOLUTE_WITNESSES_PATH`. This generates and compiles all100 shards, then compiles Assembly.lean and Representatives.lean. The output directory must be new (the runner refuses to overwrite an existing RUN.json). The retained RUN.json is from the measured run; portable path arguments and sequential assembly invocation were added to the wrapper afterward. The source bytes were independently regenerated with the retained renderer. No new full batch was run just to test the wrapper packaging.

The initial attempt stopped before any proof check because Lean required an explicit root directory when writing oleans. The corrected run passes `-R OUTPUT_DIRECTORY`; no failed proof result was counted as success. No binary oleans are retained in the repository; reproduction builds them from the retained sources using the repository toolchain.
