## Graph identities

Let A be a symmetric zero-diagonal 0/1 adjacency matrix of order49, with no C4 and minimum degree7. Nonbacktracking length-two walks from a vertex have distinct endpoints other than that vertex, giving sum over neighbors of (degree-1) at most48. Therefore all degrees are7 or8. Write h for the number of degree8 vertices.

A degree8 vertex has only degree7 neighbors and exactly one common neighbor with every other vertex. High vertices are independent. With high vertices first, write A=[[0,B],[B^T,C]], low order l=49-h, and t=B^T 1_h. Then

```
B 1_l = 8 1_h,   BB^T = 7I_h+J_h,   BC = J_(h,l),
C 1_l = 7 1_l-t,  Ct = h 1_l.
```

Here C is itself symmetric, zero-diagonal and 0/1. Each neighborhood induces a matching: two adjacent edges within it would make a C4. Every high neighbor of a low vertex must be matched to a different low neighbor. Consequently t_v<=3.

The missing-common-neighbor graph restricted to lows has adjacency

```
D = J_l+6I_l-B^T B-C²,
D 1_l = 6 1_l-t,   Dt = h 1_l-t,
DB^T = J_(l,h)-B^T,   CD=DC.
```

These are joint identities for the original integer matrices, not arbitrary spectral relaxations.

## Exact factors and nonsingularity

The high-difference space and its image under B^T contribute h-1 pairs of eigenvalues ±sqrt(7) to A, and h-1 zero eigenvalues to C. The span of 1_l,t has C quotient [[7,h],[-1,0]]. The remaining rational orthogonal space K=ker(B) intersect 1_l-perp has dimension48-2h and is C-invariant. Thus, with a monic integer polynomial psi_h,

```
char_C(x) = x^(h-1) (x²-7x+h) psi_h(x),
char_A(x) = (x²-7)^(h-1) (x³-7x²-7x+49-h) psi_h(x).
```

Integrality of psi follows by division of the monic integer characteristic polynomial by its monic integer forced factors. This does not assert that C|K is an integer matrix in an orthonormal basis.

Set a=(7+sqrt(49-4h))/2. For h=1,3 we have a>6 and t<=3, so w=a 1_l-t is strictly positive. Directly Dw=(a-1)w. For a nonnegative matrix with a strictly positive eigenvector, its spectral radius is a-1 (conjugate by diag(w) to obtain constant row sums). Hence rho(D)=a-1<6. On K, C²=6I-D, so every residual eigenvalue lambda satisfies

```
6-rho(D) <= lambda² <= 6+rho(D).
```

In particular psi_h(0) is nonzero. The other forced factors also have nonzero constant terms, so **A is nonsingular**. Its determinant is a nonzero multiple of48 when h=1 and2254 when h=3. This strengthens the earlier draft's divisibility-only observation.

## Arithmetic applicability: no exclusion yet

Modulo2, a zero-diagonal symmetric matrix of even order has square characteristic polynomial. Applying this to C gives

```
psi_h mod2 = (x²+x+1) u(x)²,
deg u = 23-h.
```

The prior `H7_CHARACTERISTIC_SQUARE_MODULE_AUDIT.md` also warns that repeated characteristic factors over GF(2) do not force additional ordinary kernel vectors: a nonsemisimple primary block can account for the multiplicity. No extra eigenvector is inferred here.

The displayed leading coefficients are compatible: the next-to-leading coefficient of u is1 for h1 and0 for h3. This partial parity check supplies no contradiction.

The Gram matrix of the low-space vectors consisting of B's rows and 1_l has determinant

```
7^(h-1) (343-22h-h²),
```

namely320 for h1 and13132 for h3. The complementary rational form K has determinant squareclass5 or67, respectively. The verifier constructs explicit 0/1 B matrices for all three incidence profiles and checks this Gram matrix directly. Therefore representability of this forced Gram block alone, including over Q_2 or Z_2, cannot exclude either profile: it already has an explicit integral representation. A useful Hasse/2-adic obstruction must also consume constraints on C, D, or a fully specified residual spectrum. No such full spectrum is supplied here.

The banked Hoffman parity theorem assumes even constant row sum. Mixed-degree A does not meet that premise. The induced h1 graph F does have row sum6, but a specific polynomial-to-J identity must still be established before applying that theorem. The mod4 square-series theorem likewise requires an actual polynomial candidate; substituting only the forced cubic for the unknown full Gram characteristic polynomial is invalid.
