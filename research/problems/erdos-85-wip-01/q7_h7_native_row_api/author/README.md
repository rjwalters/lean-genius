# Native implementation of reviewed H7 complete-row/arc traversal

filter.cpp implements the exact complete-row enumeration and pairwise arc-consistency algorithm reviewed2071/2079. native.py is a ctypes adapter; build.sh builds the small shared library. This is a bespoke necessary graph-constraint checker, not a SAT/PhaseB solver launch. No new profile has been run with this API.

At every outside vertex, candidate eligibility, sorting by(group-size,host-index), skip-first then ascending candidate traversal, residualdegree/colour-mask conditions and retained neighbour masks match2079. Every recursive call and every proposed pair of row masks consumes exactly one operation tick. Arc loops visit ascending distinct vertex pairs; removals are collected before a batch is applied. A limit exception discards incomplete local generation/current deletion batch, preserves preceding domains/events, and returns UNKNOWN. The same100000operation budget is intended; no earlier capped research case may be retried.

Input validation checks49vertices, symmetric loopless adjacency, seven independent degree8highs, C4freeness, eight degree7hosts forming a matching, and exactly onehost/nootherlow neighbour for every outside guest. New edges therefore can only join outside guests. Native failures return INVALID_INPUT and the Python bridge raises; they are never interpreted as exclusions.

The clock is absolute and shared with Python time.monotonic: macOS uses mach_absolute_time plus its timebase; other builds use CLOCK_MONOTONIC. An initial startup test caught the macOS CLOCK_MONOTONIC epoch mismatch before any graph was checked. The final code checks epoch agreement on load. Every operation tick checks the same passed absolute deadline. Wall stopping point may vary across languages, but expired deadlines always return UNKNOWN. Native serialization happens after search, as Python result construction does.

The full result has the same status, nodecount, complete/partial initial domains, ordered deletion events, empty vertex and stage/remaining fields as2079. check.py compares complete returned objects on8alreadyterminal fixed graphs at nodebudgets0,1,1000,100000:32exact equalities, plus8expireddeadline equalities and invalid-selfloop rejection. Fixtures include both original2066samples and three local-negative/three arc-negative twin4graphs. No cappedresearchcase is used. At fullbudget, aggregate native walltime including bridge/JSON was about0.0046s versus0.0463s in Python for these8cases; this sample does not guarantee a general speedup.

Independent algorithm/FFI/clock review is required before accepted research pruning. Passing fixture equality alone is not a general equivalence proof and does not exclude any new H7 profile or establish a Lean/global theorem. Large untouched twin5/crossed13 domains remain unlaunched.

Independent review found that an int counter could overflow at the maximum accepted API cap INT_MAX. The final counter is int64_t; the public cap remains int and research limits remain100000. counter_boundary.cpp directly starts the counter at INT_MAX and verifies that the next tick reaches2147483648 and raises Limit. This unit passed with undefined-behaviour sanitizer; no graph traversal was involved. All32fullobject comparisons and8expireddeadline checks passed again after this change.
