## Method (per orbit)

1. Rebuild the orbit's table from `proofs/Proofs/Certificates/h1_orbit_inventory.compact` (tag = first
   16 hex of sha1 of the sorted nonzero table), emit the CNF with the pinned `v2cnf`
   (sha256 `4bd9604c…`, image `sha256:a5ca6c4e…`), run `v2cnf check`, and require the CNF sha256 to
   equal the producer ledger's `cnf_sha256`.
2. Stream `s3://…/sat49/campaign-20260825/h1/<tag>.compact.lrat.gz` through sha256 (gz) → gunzip →
   sha256 (LRAT) → `cake_lpr`. VERIFIED only if cake_lpr prints `s VERIFIED UNSAT` and both stream
   hashes equal the producer ledger's `compact_gz_sha256` / `compact_lrat_sha256`.

The bank proofs are drat-trim LRAT with consecutive clause ids and deletions dropped
(`sat49/compact_h1_v2_lrat.py`); cake_lpr reads them directly.
