# Explicit C4 certificates for all380 faithful-action target sets

Supplement to2271. Each inverse-closed five-element connection set satisfying the required six target multiplicities is listed once, with four distinct group elements forming a cycle entirely inside the regular48-orbit W. Consecutive directed quotients are in S, so these are explicit C4 witnesses; no deficiency/F-neighbor bound is needed for these certificates.

The group ordering is reproduced in certificates.json as actual permutations. Its composition convention is a(b(i)). Every saved cycle was checked for distinct vertices and four edge memberships. The380 sets were regenerated by splitting into involutions and inverse pairs and applying the six target counts, as in2271. This supplements the enumeration with local witnesses; completeness still relies on verifying the finite connection-set cover. It is not a full graph solver run or an exclusion of nonfaithful actions.
