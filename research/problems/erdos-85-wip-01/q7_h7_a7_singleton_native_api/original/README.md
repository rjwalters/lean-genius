# Native singleton-complete residual row checker

This ports the Python singleton-complete a7 H7 row checker to C++, using accepted empty-first native API 2105 for the traversal, clock, counter, JSON and FFI infrastructure. The reference Python implementation is preserved byte for byte in `reference.py`; source paths and hashes are in `origins.json`.

Compared with 2105, validation requires complete singleton edges and exactly one single-empty and one double-empty singleton at each high. Pair vertices still have no assigned active-low edges. Singleton rows may add only pair vertices. Every row removes the high colours already represented by existing singleton neighbours, excludes existing edges, and uses the same least-uncovered-colour traversal. Existing-neighbour and selected-neighbour C4 tests remain in force. The full initial domain list is completed before testing for an empty row. Arc traversal, full-neighbour intersections, atomic deletion batches and incomplete-result handling are unchanged.

`check(adjacency, max_nodes=100000, deadline=None)` uses the same output schema as the Python implementation. Native budgets must be integer values from zero through INT_MAX. The internal signed 64-bit counter safely crosses INT_MAX before raising its limit exception. The native clock is checked against Python's monotonic epoch when the wrapper loads. Invalid graphs raise ValueError; they never produce a negative graph certificate.

The test uses only the 33 previously checked fixed singleton-complete graphs, not the new projection family. It obtains exact full-object equality in 264 budget-boundary comparisons, including generation interruption and terminal boundaries, plus 33 expired deadlines and 198 invalid-input rejections. All fixtures terminate at an empty initial row, so the arc code is additionally supported by its unchanged reviewed 2105 implementation and the Python API's independent interrupted-batch test. The sample takes 0.0446 seconds in Python and 0.00592 seconds in native code; this is not a prediction for the full family.

Build with `sh build.sh`, then run `python3 test.py`. `counter_boundary.cpp` is compiled with undefined-behaviour sanitization and checks INT_MAX+1 without graph traversal. This package adds no H7 exclusion, Lean theorem or solver-queue change. New-family use requires independent review of this port and of the reference API.
