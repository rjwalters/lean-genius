# H7: two high0 neighbourhood forms and34 exact host slots

Under the established H7 stratum, seven independent high vertices have degree8. The low support classes consist of two singleton vertices S_i^a,S_i^b for each high colour i, one pair vertex P_ij for each unordered pair, and seven empty vertices. Every low vertex has degree7 and exactly one common neighbour with each high vertex (BC=J).

Fix high0. Its eight neighbours are S0a,S0b,P01,...,P06. For every vertex v in this neighbourhood, BC=J says that v has exactly one neighbour in the same neighbourhood. Hence the induced graph is a perfect matching on eight vertices.

Up to permuting the other six high colours and swapping S0a,S0b, there are two possibilities: the two singleton vertices are matched to one another, leaving a matching of the six pair vertices; or each singleton is matched to a distinct pair vertex, leaving a matching of the other four pair vertices. These actions are legitimate relabellings of the entire prospective graph and its support classes. The checker explicitly enumerates105 perfect matchings and the1440-element local action, obtaining precisely two orbits of15 and90. It supplies one full49vertex partial skeleton for each orbit, including all fixed high-support edges. Both pass direct C4 checks.

There are34 low vertices outside this neighbourhood: twelve singletons of nonzero colour, fifteen pairs not containing0, and seven empties. Each has exactly one neighbour among the eight high0 neighbours, again by BC=J. The neighbourhood hosts therefore partition all34 outside-low vertices. Each S0 host already meets high0 and its matching partner, so needs exactly5 outside-low guests. Each P0j host already meets high0, highj and its matching partner, so needs exactly4. Thus the exact host capacities are5,5,4,4,4,4,4,4 and sum to34. A guest cannot belong to two hosts because those hosts already share high0, which would create a C4.

This gives two universal starting graphs for a possible high0-host-first decomposition. Guest assignments, their support compatibility, empty-induced graphs and all edges between guests remain unresolved. It does not rule out either form or any of the28 remaining H7 empty-graph classes; it does not retry any old search. This necessary mathematical cover has a finite symmetry audit and awaits independent review; it is not a Lean proof.
