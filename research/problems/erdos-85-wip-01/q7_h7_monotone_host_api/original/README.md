# Monotone pair-empty host assignment for a fixed high colouring

Input is a 49-vertex H/E/S graph with all 21 pair vertices and their high edges, but no pair-empty or other pair-low edges. High labels are 0..6; other labels are arbitrary. Validation checks symmetry, looplessness, C4-freeness, independent degree-eight highs, the full support multiset, complete S degrees, and empty capacity 7-2*degree_F. It permits either three mixed plus four double/double highs (a6), or seven mixed highs (a7). Same-high singleton adjacency is forbidden only at mixed highs. The missing-colour and singleton-host criteria are accepted in 2119.

`api.enumerate_hosts(adjacency, max_nodes=100000, seconds=60)` enumerates each empty's perfect matchings of its missing high colours. Empty order is decreasing F degree, then label. Pair vertices cannot receive two empty hosts. After each assignment, it tests singleton rows under the optimistic interpretation that every unassigned pair has empty-host mask zero. An empty optimistic domain rejects the entire prefix because subsequent host assignments can only remove rows. Singleton order is increasing template count (single-empty first), then label. Templates use exact support partitions; zero hosts can repeat, while nonzero hosts must be distinct and outside the singleton's forbidden empty set.

The result gives `empty_vertices` in increasing label order and `order` as indices into that list. Each leaf in `solutions` is seven vertex-bitmasks of pair neighbours, indexed by `empty_vertices`. Each item in `prunes` gives the recursion depth, the empty singleton label and seven chosen masks; unassigned entries are zero. The depth and common order distinguish assigned degree-zero empties. A leaf means all singleton domains are nonempty, not that the residual graph is feasible.

Every matching-generation node, host-recursion node, attempted host option and tested singleton-row template consumes one operation. The counter is signed 64-bit; the public cap is 0..INT_MAX. An interrupted template check never records a negative prefix. UNKNOWN preserves completed leaves and certified prefixes but makes no claim about the unvisited tree. The duration is relative to the call; family drivers must pass their remaining aggregate budget, retain UNKNOWN/unvisited cases, and never retry capped domains.

Tests use 33 old a7 fixtures and the adjacent-double a6 fixture with eleven relabellings. The separate `check_fixed_hosts` test entry point restricts every empty to its already checked host assignment, so it does not launch new family research. Exact singleton-row expectations give two surviving fixed assignments and 43 rejected prefixes. Independent increasing-P-subset star tests verify every recorded prefix. All 270 budget, expired-deadline and invalid-input checks pass. Full unrestricted calls are tested only with zero or expired budgets, so no new high/host family has been searched. An independent reviewer should audit the unrestricted traversal coverage before use.

Compile `hosts.cpp` with `clang++ -std=c++17 -O2 -shared -fPIC hosts.cpp -o hosts.dylib`; run `python3 test.py`. `counter.cpp` checks INT_MAX+1 and deadline handling under undefined-behaviour sanitization. This API alone excludes no F class, a6, a7, H7 or Erdos85.
