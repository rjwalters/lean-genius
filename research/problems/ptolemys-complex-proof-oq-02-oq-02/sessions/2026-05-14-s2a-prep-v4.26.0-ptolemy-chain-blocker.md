#### K1.1 — First example block (lines 439-444)

```lean
/-- Unit square corners {1, i, -1, -i} are concyclic on the unit circle.
    Their Ptolemy ratio R = ...
    Let's verify the equality: ‖1-(-1)‖·‖i-(-i)‖ = ‖1-i‖·‖(-1)-(-i)‖ + ‖i-(-1)‖·‖1-(-i)‖ -/
example :
    ‖(1 : ℂ) - (-1)‖ * ‖Complex.I - (-Complex.I)‖ =
    ‖(1 : ℂ) - Complex.I‖ * ‖(-1 : ℂ) - (-Complex.I)‖ +
    ‖Complex.I - (-1 : ℂ)‖ * ‖(1 : ℂ) - (-Complex.I)‖ := by
  simp only [Complex.norm_eq_abs, map_add, map_sub, map_neg, map_one,
             Complex.abs_I, Complex.abs_one, Complex.abs_neg]  -- ← Complex.abs_one / abs_neg removed
  norm_num [Complex.abs_apply, Complex.normSq_apply]            -- ← Complex.abs_apply removed
```

**Suggested replacement** (v4.26.0-compatible, using direct `‖·‖` semantics):

```lean
example :
    ‖(1 : ℂ) - (-1)‖ * ‖Complex.I - (-Complex.I)‖ =
    ‖(1 : ℂ) - Complex.I‖ * ‖(-1 : ℂ) - (-Complex.I)‖ +
    ‖Complex.I - (-1 : ℂ)‖ * ‖(1 : ℂ) - (-Complex.I)‖ := by
  -- LHS: ‖2‖·‖2·I‖ = 2·2 = 4
  -- Each RHS factor: ‖±1 ± I‖ = √2, so RHS = √2·√2 + √2·√2 = 4
  have hsq2 : Real.sqrt 2 * Real.sqrt 2 = 2 := Real.mul_self_sqrt (by norm_num : (0:ℝ) ≤ 2)
  rw [show ((1 : ℂ) - (-1)) = 2 from by ring,
      show (Complex.I - (-Complex.I)) = 2 * Complex.I from by ring]
  rw [Complex.norm_ofNat]
  -- alternatively, simp + norm_num closes after the explicit arithmetic
  sorry  -- mechanic completes via `simp [Complex.norm_*]` + `nlinarith [hsq2]`
```

The exact tactic sequence is for the mechanic to determine; the **structural** fix
is replacing the now-removed `Complex.abs_*` names with `‖·‖`-based reasoning.
